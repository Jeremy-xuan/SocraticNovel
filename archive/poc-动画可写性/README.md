# PoC · 教学动画可写性（已废弃）

**当时要回答**：在服务器上没有 Manim 的情况下，"让老师现场生成一段教学动画"到底可不可行。

**结论（2026-09-24）**：可行，但**成本不可接受** —— 走通了一条链路，但需要 10 GB 级扩散模型，
且本机（Apple M3）跑重型路线时峰值 23 GB、被 swap 拖死没跑完。轻量替代（动漫 LaMa 204 MB）能出层，
但那是**分层**不是**动画**。

**完整报告**：`docs/历史报告/取证_动画可写性PoC_2026-09-24.md` 与同目录的 `_对照轮_` 一份。

**被谁取代**：`tools/animation-gate`（动画质量闸门）＋ `tools/anim-prep`（备课预渲染）。
现在的做法是**课前预渲染 + 课上取缓存**，不再现场生成。

**这里保留**：两张关键帧截图、一段 720p 样片、以及 manim 0.21.0 的 API 摘要（当时用来判断可写性）。
