# 知识点清单 · 操作系统（cs-os）

> **用法**：课后由 AI 更新状态。三档：`[ ]` 未掌握 ｜ `[~]` 部分掌握（能复述但推不出）｜ `[x]` 掌握（能自己推出来并说清楚）。
> **判据写法**：写"**学生能说出什么**"，不写"老师讲过什么"——判据必须能当场验证。
> 🔴 **不许只因为"老师讲过了"就打 `[x]`**；`[x]` 的唯一依据是**学生自己说出来**。
> 对应教材：`materials/ch{NN}.md`（自写问答版）；OSTEP 原文链接见 `curriculum.md`。

---

## 第 1 讲 · 一个程序怎么跑起来
- [ ] **KP-1.1 进程是什么** —— 判据：学生能说出"进程 = 正在运行的程序 + 它的状态"，并指出"程序是静态的、进程是动态的"。
- [ ] **KP-1.2 虚拟化 CPU 的目标** —— 判据：学生能说出要同时满足"**看起来独占**"和"**实际共享**"两个互相冲突的目标。
- [ ] **KP-1.3 受限直接执行** —— 判据：学生能自己推出"要快就得直接跑，要不捣乱就得能打断"这对矛盾。
- [ ] **KP-1.4 用户态与内核态** —— 判据：学生能说出"为什么不能让程序随便执行特权指令"，并给出至少一个例子。
- [ ] **KP-1.5 时钟中断的作用** —— 判据：学生能说出"没有时钟中断，操作系统就再也拿不回控制权"。

## 第 2 讲 · 进程的 API 与生命周期
- [ ] **KP-2.1 fork 的语义** —— 判据：学生能解释"为什么 fork 之后父子都从同一行往下走"。
- [ ] **KP-2.2 fork 与 exec 的区别** —— 判据：学生能说出"**fork 是复制，exec 是替换**"，并指出它们是两件事。
- [ ] **KP-2.3 wait 与进程状态** —— 判据：学生能说出僵尸进程为什么存在（父进程还没取走退出码）。
- [ ] **KP-2.4 fork/exec 之间的窗口** —— 判据：学生能说出"为什么 shell 在 exec 之前要先改文件描述符"。

## 第 3 讲 · 调度：谁来决定下一个跑谁
- [ ] **KP-3.1 调度指标** —— 判据：学生能区分**周转时间**与**响应时间**，并说出它们为什么互相冲突。
- [ ] **KP-3.2 FIFO 的问题** —— 判据：学生能举出"长任务堵住短任务"的具体例子。
- [ ] **KP-3.3 SJF / STCF** —— 判据：学生能说出它们最优，但**前提是知道未来**。
- [ ] **KP-3.4 轮转（RR）** —— 判据：学生能说出 RR 换来响应时间、牺牲周转时间。
- [ ] **KP-3.5 MLFQ 的核心思想** —— 判据：学生能说出"**不是猜未来，是用过去的行为推断**"，并说出优先级升降规则。

## 第 4 讲 · 更公平的调度与多核
- [ ] **KP-4.1 彩票调度的机制** —— 判据：学生能说出"随机抽签的**期望**等于比例"。
- [ ] **KP-4.2 为什么随机也公平** —— 判据：学生能自己推出"单次不确定、长期按比例"。
- [ ] **KP-4.3 多核的缓存一致性** —— 判据：学生能说出"一个核改了内存，另一个核的缓存可能还是旧的"。
- [ ] **KP-4.4 单队列 vs 每核一队列** —— 判据：学生能说出各自的代价（迁移成本 vs 负载不均）。

## 第 5 讲 · 内存：每个程序都有自己的世界
- [ ] **KP-5.1 地址空间** —— 判据：学生能说出"地址是**假的**（虚拟的），物理位置才是真的"。
- [ ] **KP-5.2 代码/堆/栈的布局** —— 判据：学生能在图上指出三者的位置与增长方向。
- [ ] **KP-5.3 malloc / free 的语义** —— 判据：学生能说出"free 不是清零，是**交还**"。
- [ ] **KP-5.4 悬垂指针与内存泄漏** —— 判据：学生能各举一例并说出后果。

## 第 6 讲 · 地址翻译：硬件怎么帮我们作弊
- [ ] **KP-6.1 基址 + 界限** —— 判据：学生能说出这两个寄存器各自解决什么问题（重定位 / 隔离）。
- [ ] **KP-6.2 谁翻译、谁定规则** —— 判据：学生能说出"**硬件执行翻译，操作系统设定规则**"。
- [ ] **KP-6.3 内部碎片（基址界限的问题）** —— 判据：学生能说出"栈和堆之间那块空闲被浪费了"。
- [ ] **KP-6.4 分段** —— 判据：学生能说出分段怎么缓解碎片，以及**为什么它又会带来外部碎片**。

## 第 7 讲 · 分页与 TLB
- [ ] **KP-7.1 分页的机制** —— 判据：学生能说出"地址被切成页号 + 页内偏移"。
- [ ] **KP-7.2 页表存在哪** —— 判据：学生能说出页表在内存里，并指出"那访存次数会变多"。
- [ ] **KP-7.3 TLB 的必要性** —— 判据：学生能自己算出"没有 TLB 每次访存要多几次内存访问"。
- [ ] **KP-7.4 局部性** —— 判据：学生能说出"**TLB 是在赌程序有局部性**"。

## 第 8 讲 · 换页：内存不够用的时候
- [ ] **KP-8.1 换出/换入与存在位** —— 判据：学生能描述一次页错误的完整流程。
- [ ] **KP-8.2 最优策略（OPT）** —— 判据：学生能说出它为什么**只能当标尺、不能实现**。
- [ ] **KP-8.3 LRU 与近似** —— 判据：学生能说出"精确 LRU 太贵，所以用 Clock 近似"。
- [ ] **KP-8.4 抖动（thrashing）** —— 判据：学生能说出"工作集大于物理内存时会恶性循环"。

## 第 9 讲 · 并发：两个线程同时改一个数
- [ ] **KP-9.1 线程与进程的区别** —— 判据：学生能说出"线程共享地址空间、进程不共享"。
- [ ] **KP-9.2 竞态条件** —— 判据：学生能说出"`counter++` 是**多条指令**，中间可以被插队"。
- [ ] **KP-9.3 临界区与互斥** —— 判据：学生能自己划出代码里的临界区。
- [ ] **KP-9.4 不确定性** —— 判据：学生能说出"同一个程序跑两次结果可能不同"的原因。

## 第 10 讲 · 锁：把混乱关进笼子
- [ ] **KP-10.1 test-and-set** —— 判据：学生能说出"**锁的原子性来自硬件的一条指令**"。
- [ ] **KP-10.2 自旋的代价** —— 判据：学生能说出自旋在单核上为什么几乎必然浪费。
- [ ] **KP-10.3 用锁保护数据结构** —— 判据：学生能说出"给链表加锁"和"给整个结构加一把大锁"的取舍。
- [ ] **KP-10.4 锁的粒度** —— 判据：学生能说出粒度变细换来并发、付出复杂度。

## 第 11 讲 · 条件变量与信号量
- [ ] **KP-11.1 条件变量三件套** —— 判据：学生能说出 lock / wait / signal 各做什么。
- [ ] **KP-11.2 为什么用 while 不用 if** —— 判据：学生能说出"**醒来时条件可能已经又变了**"。
- [ ] **KP-11.3 信号量的两种用法** —— 判据：学生能各举一例（互斥 / 顺序）。
- [ ] **KP-11.4 生产者-消费者** —— 判据：学生能说出不加锁或用错锁时会怎么坏。

## 第 12 讲 · 并发 bug 与事件驱动
- [ ] **KP-12.1 非死锁缺陷** —— 判据：学生能区分"原子性违反"与"顺序违反"。
- [ ] **KP-12.2 死锁的四个必要条件** —— 判据：学生能逐条说出并指出破坏哪一条最容易。
- [ ] **KP-12.3 死锁的预防 vs 检测** —— 判据：学生能说出两者的代价差别。
- [ ] **KP-12.4 事件驱动** —— 判据：学生能说出它为什么能绕开锁，以及它的代价（阻塞调用）。

## 第 13 讲 · 文件与目录
- [ ] **KP-13.1 inode** —— 判据：学生能说出 inode 里存什么、不存什么（**不存文件名**）。
- [ ] **KP-13.2 目录的本质** —— 判据：学生能说出"目录里存的是**名字 → inode 号**的映射"。
- [ ] **KP-13.3 一次 write 的路径** —— 判据：学生能按顺序说出从 `write()` 到磁盘经过的几层。
- [ ] **KP-13.4 文件描述符** —— 判据：学生能说出它为什么只是一个整数索引。

## 第 14 讲 · 崩溃之后：日志与一致性
- [ ] **KP-14.1 多处写的问题** —— 判据：学生能说出一次更新要写几处、中途崩溃会留下什么。
- [ ] **KP-14.2 FSCK** —— 判据：学生能说出它是**事后**扫描修复，以及为什么慢。
- [ ] **KP-14.3 日志（journaling）** —— 判据：学生能说出"**先记账再动手，崩溃后可重放**"。
- [ ] **KP-14.4 元数据日志 vs 全数据日志** —— 判据：学生能说出两者的性能与安全取舍。
