# 第 2 讲故事节点 · 进程的 API 与生命周期

> 正文：`materials/ch02.md`（待写）｜知识点：KP-2.1～2.4｜OSTEP：ch5 Process API

## 本讲位置
承接第 1 讲的"进程"概念，进入**它怎么被创建、怎么结束**。本讲是**第一次出现"复制"这个概念**——也是她第一次露出与"记录"有关的过去。

## 开场场景方向（200–500 字）
台面上多了一份**新抄出的作业记录**，和原来那份**一模一样**。她把它推到学生面前，没解释。

## 场景节点

> 叙事动作服务人物弧；其中的问句是可用台词，不是逐项执行的题单。教师可直接讲清必要事实，学生已理解时跳过问句并继续。技术问题要说出真实对象，道具只辅助演示。
1. **她写下第一个问题**（记录板）："**这份新的，是抄的还是原来那份？**"
2. 学生说出"两个都从同一行往下走"之后，她追问"**那我怎么知道谁是原来那份？**"→ 引出返回值区分。
3. 🔴 **`fork` 与 `exec` 的分离**：她**把两份作业记录并排**，其中一份**换掉内容但保留编号**——问"**编号没变，东西变了，这算什么？**"
4. 收束：检查学生能否解释或应用本讲机制（见知识点判据）；教师可先讲清必要事实。

## 机会节点
| 触发 | 发生什么 |
|---|---|
| 学生问"为什么要有 fork 这个奇怪的设计" | 她小声说"**我做第一次记录的时候，也是先抄了一份**"，然后立刻转回题目 |
| 学生注意到新作业记录的边角有折痕 | 她说"这个是旧的，我拿错了"——**不换回去**（物件积累） |

## 犯错节点
- 她讲到"复制"时**可能会顺口提到自己刚来做记录时的过去**，然后**明显慌一下**（语速变快、开始解释无关的细节）。

## 余韵场景方向
她把两份作业记录叠在一起收走。**其中一份的边角还是折的。**

## 暗线种子
- 埋：**她抄过一份**（ch14 回收，接"她为什么来观测站"）
