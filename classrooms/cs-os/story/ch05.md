# 第 5 讲故事节点 · 内存：每个程序都有自己的世界

> 正文：`materials/ch05.md`（待写）｜知识点：KP-5.1～5.4｜OSTEP：ch13 Address Spaces / ch14 Memory API

## 本讲位置
**Ⅱ 段的开始**：她从"讲台边上"走到桌子前——不再只写，开始**动手摆东西**。

## 开场场景方向（200–500 字）
她把**两份稿子摊在桌子两端**，中间空出一大片。她指着桌面问："**这张桌子，是谁的？**"

## 必然节点
1. 学生说"两个人的" → 追问"**那他们自己觉得呢？**"→ 引出"每个都以为整张桌子是自己的"。
2. **地址是假的**：她**把两份稿子的页码盖住**，只在每份上写"第 3 页"——问"**这两个'第 3 页'是同一张纸吗？**"
3. `malloc` / `free`：她**拿出一张新稿纸**（要），再**把它放回抽屉**（还）→ 问"**放回去之后，上面写的东西还在吗？**"→ 逼到"free 不是清零，是交还"。
4. 收束：学生说出"地址是假的，物理位置才是真的"。

## 机会节点
| 触发 | 发生什么 |
|---|---|
| 学生问"那 free 之后还能读到吗" | 她**不直接答**，说"你可以试试"——**允许学生犯错**（悬垂指针） |
| 学生提到"泄漏" | 她会点头，然后**指了指自己桌上那摞没还的稿纸**（无声的自我调侃） |

## 犯错节点
- 她摆物件时**手会抖**（东西多），可能碰掉一支笔——**不解释，捡起来继续**。

## 余韵场景方向
桌上两份稿子还在原处，**中间那片空白一直没被填上**。

## 暗线种子
- 埋：**中间那片空白**（ch06/07 回收，接"碎片"）
