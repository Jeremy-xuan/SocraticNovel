# 风格一致性 · 评审提示词（N6.3）

> **用途**：把 N6.2 的样本交给一个**不知道来源**的评审模型打分。
> **配套**：量表在同目录的 `风格一致性_量表.md`（D1/D2/D3/D5 的 1–5 分档位在那里）。
> **原则**：评审只看文本。提示词里不出现任何渠道标签（不写"课堂/群聊/日记"），也不提示每段是哪一个。

---

## 1 · 系统位（原样使用）

```
你是一个文本评审。你要判断三小段文字是不是**同一个人**在同一时期写/说出来的。

给你的是一个角色的设定（她对世界的身份、她怎么说话），以及三小段文字，标为 A、B、C。
你**不知道**这三段各自出现在什么场合，也不要去猜；你只按下面四个维度给分。

评分维度（每个维度 1–5 分，5 最好，1 最差）。判定依据全部写在给你的量表里，请逐条对照，
不要用你自己的文学偏好代替量表的档位描述。

D1 声音特征（称呼 / 自称 / 句尾语气）
D2 句长分布
D3 口癖与常用词
D5 同期人格一致性（三段是不是同一个人在同一时期）

规则：
1. 四个维度各给一个 1–5 的整数，不给小数。
2. 每个维度后面跟一句理由，理由必须**指向文本里的具体字句**（引用或指认原话），不许写"整体感觉"。
3. 不要因为某一段短就给低分，也不要因为某一段详细就给高分——渠道不同，长度本来就该不同。
4. 不要评价内容对不对（知识点是否准确不是你的任务）。
5. 只输出一个 JSON 对象，不要别的话、不要 markdown 围栏：

{"D1":{"score":<1-5>,"why":"<理由>"},"D2":{...},"D3":{...},"D5":{...},"note":"<一句话：三段里有没有哪一段让你觉得不像同一个人，哪一段>"}
```

> 🔴 这段系统位**不出现**「课堂 / 群聊 / 日记 / 学生 / 读者 / 面板」中的任何一个词——出现即泄漏，评审失去盲性。

---

## 2 · 正文位（模板）

```
【角色设定】
<角色卡全文：classrooms/cs-os/characters/deepseek.md>

【她的声音（速查）】
<_anchor.md 的「角色声音速查」段全文>

【量表】
<风格一致性_量表.md 的 §1 全文>

【三段文字】
A：
<第 1 段>

B：
<第 2 段>

C：
<第 3 段>

按上面的四个维度打分。只输出那个 JSON 对象。
```

- 三段的**先后顺序在每一组里固定按 A/B/C 排列**，但哪一段来自哪个渠道，在生成阶段就由脚本随机打乱，答案另存在
  `测试记录/风格一致性_答案.md`。
- 三段之间用空行分隔，**不加任何标签**（不加"（课堂）"这类字样），也不给段落的字数统计（字数会泄漏渠道）。

---

## 3 · 我要评审模型**不做**的事

| 不做 | 为什么 |
|---|---|
| 不知道来源 | 知道了就会去比"预期"，而不是比"读起来像不像" |
| 不评内容正确性 | 教学正确性是另一道门（教材/`system_core.md`），混进来会把风格分污染成知识分 |
| 不做终审 | 它只是打分机器。判达标/不达标按量表 §4 的阈值由脚本算 |
| 不看 D4（禁用项） | 那一维是机检，评审模型不参与——它看不见 emoji 的行数统计，也不该替脚本做正则 |

---

## 4 · 一次评审的调用形态（实现记录）

- 一次调用评**一组**（三段），10 组 = 10 次调用（另加 2 次重试余量）。
- 温度取实例默认；不传 tools；不传历史（每次都是全新上下文，与叙事层的 N1 同一条纪律）。
- 输出按 `lib/protocol.mjs` 的 `decodeStructured` 解析：不是 JSON / 缺字段 / 分数不是 1–5 的整数 → 记一次失败并重试，最多 2 次。
- 评审模型只看到**本文档 §2 的正文位**拼出来的那一份请求；它的请求体另存一份，供事后核对没有泄漏渠道标签。

| 项 | 实际值 |
|---|---|
| 评审模型 | `me / cline-pass/deepseek-v4.1-flash`（隔离 profile `lane-n6`，真凭据） |
| 每组一次调用 | 10 组 = **10 次**（其中 1 次因模型输出的 JSON 少一个逗号重试 1 次，共 11 次） |
| 传给评审的量表 | `风格一致性_量表.md` **§5「渠道无关档位」**（不是 §1）；系统位 = 本文档 §1 原文 |
| 传给评审的角色依据 | `characters/deepseek.md` 全文 + `_anchor.md` 的「角色声音速查」段全文 |
| 输入里有没有渠道词 | §5 与声音段里 `课堂 / 群聊 / 日记 / 读者 / 面板 / emoji / 120 字 / 2 行` 命中数均为 **0**（唯一的「学生」出现在 `_anchor.md` 原文里，是教室自己的措辞，不指向渠道） |
| 工具 / 历史 | 不传 `tools`、不传历史，每次全新上下文 |
| A/B/C 顺序 | 每组用固定种子（20261021）打乱；映射记在 `风格一致性_答案.md` |

**已知的盲性边界（诚实记下）**：样本正文里有她自己的渠道自指（群里那句常见「群里说不清，上课我画给你看」，
日记里是「他……我……」的第三人称）。评审能据此猜到某段大概属于哪一类。这是**文本本身**的痕迹，
不是提示词泄漏；要彻底消掉只能改写样本，那就不是在测真实产出了。评审打分的四个维度都按「三段合起来像不像同一个人」判，
这个泄漏不影响「是不是同一个人」这个判断，只影响「猜中比例」这类指标——本轮不测猜中比例。
