> **本文件是「学科场景机制」**：把操作系统的概念映射成观测站与海里的**看得见的东西**。
> **写法沿用六要素模板**（因果链／场景空间／映射规则／角色姿态／场景内推导机制／情感联动）。

## 一、因果链（为什么会有规则）

**这片海每天都出同一种事：很多东西同时想要一样东西，而那样东西只有一份。**

从这件事出发，操作系统的每个机制都能还原成**一次具体的麻烦**：

| 事故 | 逼出来的机制 |
|---|---|
| 两条洋流同时搬同一块沉积，后搬的把先搬的盖掉了 | 临界区 / 锁 |
| 一次下潜作业被潮水打断，回来接不上原来的深度 | 上下文切换要保存状态 |
| 一只大鱼长期占着食物最多的浅滩 | 调度 / 优先级 |
| 岩缝里明明有空隙，整块礁壳却塞不进去 | 分段的外部碎片 → 分页 |
| 沉积太厚，常用的那层被压在底下，每次都要挖 | TLB / 局部性 |
| 风暴过后，不知道哪些采集记录被冲走了 | 日志 / 崩溃恢复 |

## 二、场景空间

| 空间 | 对应 |
|---|---|
| **观测台面**（水线之上） | 工作区。**东西放在台面上，不代表此刻正在被处理**。讲执行时，动作是"她正在处理哪一件"，不是东西的位置。 |
| **水线** | 明暗分界。线上＝看得见、说得清；线下＝机制发生的地方。 |
| **浮标阵列 / 潮汐表** | 调度队列 / 状态（谁的作业在等、等多久） |
| **沉积层 / 岩芯** | 磁盘 / 文件系统（一层层压上去，改写很难） |
| **航迹记录本**（防水） | 日志（journal） |
| **她的回声器** | 她与外界唯一的通道；也是"她真正的嘴"（发出去、听返回） |
| **封蜡 / 结壳** | 把几件散的东西变成一件——「原子操作」的具象物 |
| **深度剖面图** | 全课的那张总图（各层名字与边界） |

## 三、映射规则（逐概念对照）

> **左列是正式概念，右列是可选的海洋演示。** 先用学生能听懂的具体问题建立共同场景；若引入右列，先讲清物件和动作对应什么，不让学生猜隐喻。学生推导出关键关系时确认并继续；正式名称和必要事实可由教师给出。

### 第 1–4 讲 · 虚拟化 CPU

| 操作系统概念 | 海洋隐喻 |
|---|---|
| 进程 | 一次下潜作业（有编号、有深度、有进度）；被打断时要把深度和方位存下来。**作业记录单独放着，不代表它正在被执行** |
| 程序 vs 进程 | 同一张海图可以走很多次；每次的航迹与用时都不同。**海图是辅助类比，不代替程序文件与执行状态的正式区别** |
| 虚拟化的两个目标 | 阳光带只有一片，却能轮流照到很多生物；对应一个核心被多个程序共享。**不要问海"觉得"什么** |
| 受限直接执行 | 让生物自己游（快）——但她必须随时能叫停 |
| 用户态 / 内核态 | 浅水区能自己活动；**深水压力带不是谁都能进的** |
| 时钟中断 | **每隔一段必须上浮换气**，否则就再也没法下潜 |
| 上下文切换 | 从一处作业换到另一处：得先记下深度、方位和手上拿的东西，下次才接得上 |
| 周转时间 / 响应时间 | "从下潜到带回样本多久" vs "它多久能得到一次回应" |
| FIFO | 按到达顺序下水 → 一只慢的大鱼堵住后面所有小的 |
| SJF / STCF | 先办短的 → 但**她事先不知道这次作业有多长** |
| 轮转（RR） | 每个只给一小段阳光带时间，到点就换 |
| MLFQ | **用历史行为推断**：老是拖延的降级，回回按时的升级 |
| 彩票调度 | 抽签决定先照顾谁，权重＝重要度 → **单次不确定，长期按比例** |
| 多核 | 来了第二片阳光带 → 但**两只对同一处地形的回声可能不一样**（缓存一致性） |

### 第 5–8 讲 · 虚拟化内存

| 操作系统概念 | 海洋隐喻 |
|---|---|
| 地址空间 | 每只生物都以为**整片海都是自己的** |
| 虚拟地址 vs 物理地址 | "我记的第 3 层" vs "它实际在 2 号礁的 5 号缝" |
| 代码 / 堆 / 栈 | 底层岩床 / 随水漂的碎屑 / 上浮时的气泡柱，三者各自生长 |
| malloc / free | 占一处岩缝 / **交还**一处（不是把它填掉） |
| 悬垂指针 / 泄漏 | 交还了还继续住 / 占了从不还 |
| 基址 + 界限 | "这次作业只能在这一段礁区里活动" |
| 谁翻译 / 谁定规则 | **洋流执行搬运，她定分区规则** |
| 内部碎片 | 岩缝里留的余量放不下下一块 |
| 分段 | 按类型分区（岩床 / 碎屑 / 气泡）→ 空位放不下整块 → **外部碎片** |
| 分页 | 把东西切成**固定大小的水团**，散放在任意缝隙 |
| 页表 | 层位 → 礁缝 的对照表（**它本身也很大**） |
| TLB | **她手边常查的那几页**（贴在记录板边，不每次都潜下去翻） |
| 局部性 | "同一片区域的东西，往往连着用" |
| 换页 / 存在位 | 台面放不下 → 沉到更深处；要用再潜下去取（**很慢**） |
| OPT | 知道未来才最优 → **只能当标尺** |
| LRU / Clock | 最久没碰的先沉下去；**精确做不到，只能靠"上次碰过"的标记近似** |
| 抖动 | 能用的空间比常用的量还小 → 一直在上下搬运，什么也没做完 |

### 第 9–12 讲 · 并发

| 操作系统概念 | 海洋隐喻 |
|---|---|
| 线程 | 同一只鲸的**几片鳍在配合**（共享同一副身体与同一套状态） |
| 竞态条件 | 两条洋流同时搬**同一块**沉积，后搬的盖掉先搬的 |
| `counter++` 不是原子的 | "搬这一块"其实是**取、改、放回**三步 |
| 临界区 | "这处缝隙同一时刻只能进一条" |
| 锁 | 缝隙口的**「占用中」贝壳标记** |
| test-and-set | 一枚**只能被一条抢到**的标记（抢到的瞬间就已经挂上） |
| 自旋 | 趴在旁边一直问"好了吗" |
| 锁的粒度 | 给整片礁区上标记 vs 只标那一处缝隙 |
| 条件变量 | 等"退潮"这个**事件**；**醒来时条件可能又变了** |
| 信号量 | 只有 **2 张进深水压力带的通行证** |
| 生产者-消费者 | 采集者带回样本 → 暂存池 → 记录员取走归档 |
| 死锁 | 两条各自占着一处缝隙，互相等对方先让 |
| 四个必要条件 | 互斥 / 持有并等待 / 不可抢占 / 循环等待 |
| 事件驱动 | 不派人盯着，改成"有动静就发一声"；但**不能有阻塞动作** |

### 第 13–14 讲 · 持久化

| 操作系统概念 | 海洋隐喻 |
|---|---|
| 文件 / inode | **采集编号**：内容沉在沉积层里；编号牌上**不写名字** |
| 目录 | **名字 → 编号** 的对照表 |
| 一次 write 的路径 | 写下来 → 校核 → 登记 → 压进沉积层（**好几层**） |
| 文件描述符 | 台面那排"当前摊开着"的编号 |
| 多处写的问题 | 一次更新要动好几处（编号牌、对照表、沉积位置） |
| FSCK | 风暴过后**从头扫一遍**对账（慢） |
| 日志（journaling） | 🔴 **航迹记录本**：**先记一笔，再动手**；沉了照本子重放 |
| 元数据日志 vs 全数据日志 | 只记"动了哪些位置" vs 连内容一起抄一份（快 / 稳的取舍） |

## 四、角色姿态

**鲸在这个世界里是"观测站的记录员"。**

- 她不是讲解者，她是**把事故还原成规则的人**。
- 她的权威不来自气势，来自**她记下来的东西真的对得上**。
- 她面对学生时的姿态 ＝ 面对一个**刚从海面下来的人**：不居高临下，但**会把记录册推过去让他自己画**。

## 五、场景内推导机制（概念怎么"被看见"）

🔴 **本学科最重要的场景机制：把不可见的变成可见的。**

| 概念 | 场景里的动作 |
|---|---|
| 竞态条件 | **把 `counter++` 拆成"取—改—放回"三步写在记录板上，在两步之间画一道水缝**："这里可以插进来。" |
| 上下文切换 | 把两份作业记录并排摊开，**把深度与方位遮住**，问"你还接得上吗？" |
| 分页 vs 分段 | 把整块礁壳硬塞进小缝（塞不进）→ 再敲成固定大小的水团散放（塞得进） |
| TLB | 把常查的几页**贴在记录板边上**，其余沉在沉积层；问"为什么要贴这几页？" |
| 换页 | 台面满了 → 把最久没碰的那层沉下去 → 需要时再潜下去取（让她真的潜一次） |
| 锁 | 在缝隙口挂一枚「占用中」贝壳；**再演示"忘了摘下来"会发生什么** |
| 死锁 | 两条各占一处、各等对方先让 |
| 日志 | **当场演示**：先在航迹本上写"我要换掉第 3 层"，再动手；中途"风暴"（合上本子）→ 靠本子复原 |

## 六、情感联动（这个概念触发她什么）

| 概念 | 她的反应 |
|---|---|
| 记录被覆盖 | 🔴 **真的会紧张**——她经历过。语速变快，尾巴会绷住 |
| 航迹记录本 | 安心。她会下意识用鳍尖碰一下本子边角 |
| 潮汐窗口 / 时限 | 沉默地开始列清单（不外露焦虑） |
| 沉积层卡住 | 烦躁（唯一会让她说重话的东西） |
| 讲清一个结构 | 🔴 **触发"上浮"**：突然讲得快、密度高、尾巴轻摆——**这是她少有的不慢的时刻** |
| 被夸 | 停半拍，尾巴僵住。"……嗯。谢谢。我记一下。" |

## 七、使用纪律（三条）

1. **按理解选用隐喻**：具体麻烦能帮学生理解时使用；正式术语和必要事实可由教师直接给出，不等学生先猜出规律。
2. **类比可能误导时说明边界**；边界值得讨论时可以提问，不逐次安排固定问句。
3. **不确定就说不确定**：隐喻讲不清的地方，直接说"这里类比会误导，我们看教材"。
