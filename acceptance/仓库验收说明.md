# 仓库级验收（`check.mjs`）· 说明

> 本文件**只说明怎么跑、跑了什么、现在什么状态**。它不是判据本身 —— 判据在 `check.mjs`
> 与它调用的各子包自检里。`acceptance/README.md` 讲的是**那条花钱的端到端流水线**
> （**现行口径一律以它为准**：退出码、教学动画、环境变量、报告怎么读）；
> 本文件讲的是**根目录那条不花钱的仓库级入口**。两者互补，不互相替代。

---

## 一 · 怎么跑

从仓库任意位置调用都可以（所有路径按仓库根解析，脚本内部没有绝对路径）。

```bash
node check.mjs                  # 全部（①②③④⑤⑥⑦⑧）
node check.mjs --skill          # 只跑 ①②（纯本地，不需要引擎依赖，秒级）
node check.mjs --stage3-shots   # 额外跑 STAGE-3 的 12 屏浏览器断言（需要 playwright）
node check.mjs --node <exe>     # 指定 node（默认 process.execPath）
```

**退出码**：`0` = 全部通过；`1` = 有任一检查失败。**N/A 项不算通过、也不算失败**（见 §三）。

🔴 关于 `node`：默认用 `process.execPath`。在 DSH 的 harness 里它可能是 **Electron 壳**
（`DSH Desktop Helper … ELECTRON_RUN_AS_NODE=1`，Node 24.18.1）——实测能跑通本脚本全部步骤；
要换成系统真 node 就用 `--node /opt/homebrew/bin/node`。本脚本**不做**"是不是 Electron"的启发式猜测。

## 二 · 八步各查什么

| # | 步骤 | 查什么 | 依赖 |
|---|---|---|---|
| ① | 技能自检 | `skills/socratic-classroom/validate` 判镜像教室**内容**（必需文件／声明材料／讲次／教材正文） | 该目录已 `npm ci`（`yaml`） |
| ② | 真源 ↔ 镜像 | `classrooms/cs-os` ↔ `skills/socratic-classroom/classroom` **全文件 sha256** 一致（排除 `.DS_Store`）；文件数按盘上实际内容列举 | 无 |
| ③ | Live2D 静态完整性 | `clients/live2d-host`：每个 `script` 的目标文件在盘上（glob 展开须有命中）＋ 包内全部 JS/CJS/MJS 逐文件 `node --check`；`build`/`capability` 记 **N/A** | 无（`vendor/`、`samples/` 未分发） |
| ④ | inject-hide | `clients/inject-hide` 的 `npm test`（驱动浏览器半边的真实产物） | 无（不装依赖也能跑） |
| ⑤ | classroom-ui | `clients/classroom-ui/test/panel.test.mjs` | 无 |
| ⑥ | STAGE-3 原型 | `prototypes/stage3/tools_selfcheck.mjs`（零依赖静态自检，42 项）；**可选**再跑 12 屏浏览器断言 | 浏览器断言需 playwright |
| ⑦ | 验收机核 | `acceptance/` 的**静态三守卫**（`footprint-self-test` / `whitelist-self-test` / `frequency-parity`）＋ `dynamic-blocks.test.mjs` | 无（都不跑会话、不花钱） |
| ⑧ | 引擎单元测试 | `plugins/socratic-engine` 的 `npm test` | 该目录已 `npm ci` |

**不写死的东西**：文件数（按盘上实际列举）、绝对路径（全部相对仓库根解析）、外部 `shasum`
（sha256 一律 `node:crypto` 现算）。**spawn 异常显式抛出**：命令没跑起来会以异常报出来，
不会伪装成"退出码 1"。

## 三 · 第三态：N/A 与显式开关

本仓库**不把"没验"写成"通过"**：

| 形态 | 什么时候出现 | 算什么 |
|---|---|---|
| **N/A** | `clients/live2d-host` 的 `vendor/`、`samples/` 未随仓库分发 → `npm run build`／`npm run capability` 在本仓库跑不起来 | 不算通过，也不算失败；本步只判"脚本目标在盘上 ＋ 逐文件语法" |
| **N/A** | 不加 `--stage3-shots` 时，12 屏浏览器断言不跑 | 同上；要验就显式加这个开关 |
| **失败** | 入口文件不存在、退出码非 0、语法检查报错、`npm ci` 未做 | 判红，退出码 1 |

**为什么 12 屏是显式开关**：它需要 playwright。虽然本机全局 `npm root -g` 下确实有
（`tools_shots.cjs` 会按 `$STAGE3_PLAYWRIGHT` → 仓库根 `node_modules/playwright` → 全局
`npm root -g` 顺序解析），但**不把"全局装了 playwright"当成仓库验收的默认前提**。
该开关只传 `--no-shots`：**只断言不落图**，不给版本库留运行产物。

### 📌 `--skip-session` 的退出码：`exit 1` 未必是坏了

`./acceptance/run.sh --skip-session` 是那条**不花钱**的旁证路径（冻结 → 装载 → 逐文件哈希复核 →
技能包自检两份 → 零接触写足迹守卫）。它的完整退出码表与"怎么拿到全绿"以
`acceptance/README.md` 的「退出码」「教学动画」「想拿到一次全绿的 `--skip-session`？」三节为准；
此处只记最容易误读的一条：

- 🔴 **现盘 `classrooms/cs-os/classroom.yaml` 声明了顶层 `animation: {enabled: true}`。**
  引擎的设计是「教室声明了动画、但部署没配渲染环境 → **装载时报错**」（有意为之，不静默降级），
  而**这条省钱路径也一样** → **不配 `SOCRATIC_ANIMATION_ENV_DIR` / `SOCRATIC_ANIMATION_GATE`
  就是 `exit 1`，那是设计行为，不是 bug**；配好渲染环境**才可能**拿到 `0`。
- `exit 2` ＝ 环境不成立（找不到 node／dsh CLI，或 `DSH_HOME` 没隔离）。本环境的 `DSH_HOME`
  **本来**就指向真 harness，所以要 `env -u DSH_HOME ./acceptance/run.sh --skip-session`，
  或把 `DSH_HOME` 显式指到 `$ACCEPT_DSH_HOME_ROOT` 之下 —— 否则 `run.sh` 会**正确拒绝运行**。
- 不想在这台机器上验动画，就用**显式降级**（会留痕，不是静默跳过）：
  `./acceptance/run.sh --skip-session --disable-classroom-animation --animation-disable-reason "<为什么这台机器上关掉>"`。
- 隔离的 `DSH_HOME` 里**没装技能副本**时，「发现链路」那一项记"未安装＝没验"（**不是通过**）——
  所以"全绿的 `--skip-session`"要同时满足渲染环境、技能副本、`DSH_HOME` 隔离三件事。

## 五 · 本入口**不**覆盖什么（诚实清单）

- **不跑会话**：`acceptance/run.sh` 那条端到端流水线（冻结 → 装载 → 真实课堂 → 六条断言 →
  归档）**不在本入口内** —— 它要花钱、要隔离 `DSH_HOME`、要 dsh CLI。要看真实课堂有没有按设计
  发生，跑 `./acceptance/run.sh`（见 `acceptance/README.md`）。
- **不跑 `a2-replay.mjs`**：它需要 `acceptance/runs/` 下至少一次完整跑；`runs/` 不入库
  （见 `.gitignore`），所以在本仓库默认状态下它只能如实报"无可复评对象"。
- **不做 Live2D 的真跑**：`build`／`capability` 的 N/A 就是"没验"；补齐 `vendor/`＋`samples/`
  之后要在那台机器上真跑一次才算。
- **不做跨平台验证**：`check.mjs` 用 `shell:true` 兼容 Windows 的 `npm.cmd`，但**只在 macOS 上实测过**。
