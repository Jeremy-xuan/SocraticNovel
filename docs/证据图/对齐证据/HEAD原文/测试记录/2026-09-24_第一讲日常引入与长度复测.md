# 第一讲：日常引入与课程长度复测

日期：2026-09-24。使用 Claude Code CLI，在当前 `classrooms/cs-os` 文件的隔离副本中以默认模式连续进行四轮。测试者输入由 Codex 模拟，模型实际路由为 `deepseek-v4.1-flash[1m]`。教师回复为原始输出，没有润色；仅开放读取工具，原仓库课堂进度未被测试改动。

## 观察

- 先问“一个人如何推进两份稿”，学生答“轮流”后明确映射到一颗核心与两个程序，并在同一轮讲进程状态与上下文切换；没有停在日常答案处。
- 随后沿“持续计算不让位 → 定时器中断 → 特权限制与系统调用”推进，并用 A/B 的完整时间线检查能否应用；没有宣布下课或跳去下一讲。
- 人物的迟疑语气、在白板前变流畅的反差和编辑部物件贯穿四轮；技术问题仍明确写出程序和 CPU。
- 这是默认模式的模拟会话。用户截图处于 plan mode，曾出现开课方案说明；截图底部的英文 recap 是 CLI 会话提示。原截图中的教师没有更新课次或明确下课，但讲完一段便无下一步，造成“答一次就结束”的实际体验。
- 测试覆盖第一讲的四轮，不等于 30–45 分钟整课或其余 13 讲的效果保证。

## 原始对话

### 第 1 轮

**测试者：**
开始吧

**小鞠（原文）：**

傍晚六点过后，编辑部里只剩下一盏台灯。

装订机停了。不是坏了——今天该装订的都装订完了，它停在那儿，像一件收工的工具。靠墙那排档案柜有一个抽屉半开着，滑轨上还留着谁白天拉过的手感。

小鞠知花把两份稿子摊在长桌上，摊得整整齐齐，两份之间留出一段空隙。左边那份压着批注，页角卷起来；右边那份只写了一半，后半截是空的。

她抬眼看了一下你——今天刚来报到的实习编辑——视线很快移开，落回桌面上。她没有开口。

她从笔筒里抽出白板笔，站起来走到白板前。白板右下角还留着一片没擦干净的旧字迹，是上个月排期表的一部分，几个日期被划掉、又留着没抹。她看了那块地方一眼，笔尖绕开了它。

然后她写：

**今天两份稿都要往前推进。只有我一个人改。**
**怎么安排？**

写完，她把笔搁回槽里，侧身让开，两只手垂在身前，等你。

台灯的光落在长桌中间那道空隙上。两份稿子，谁也没比谁靠前。

### 第 2 轮

**测试者：**
轮流处理工作？

**小鞠（原文）：**

她点了一下头，很轻。

"嗯。轮流。"

她说完这两个字就停住了，像是确认完了、接下来该由别人接话。然后她转回白板，拿起笔——手一碰到笔，节奏就变了。笔尖落在板上，字一行一行往下走，快，而且间距匀。

**一个人一次改一份　　↔　　一颗核心一次给一个程序执行机会**
**两份都要推进的稿　　↔　　音乐播放器和浏览器，都要用 CPU**
**轮流改　　　　　　　↔　　两个程序轮流获得执行机会**

她写完最后一行的横线，笔尖在句末顿了一下，才把笔放下。

"这里……先等一下。"她侧过身，指了指那两行字，"稿子不是进程，我也不是 CPU。只是'同一时间能做的事只有一件'这件事，两边长得一样。"

她又把笔拿起来，在第三行下面补了一小段。这次写得更快，几乎没停。

**程序文件：静态的，放在那里不动**
**程序的一次执行 + 它当前的状态：进程**

"程序文件本身不会跑。"她说，"跑起来的那个东西，叫进程。它可能正在执行，也可能在等——等 CPU，或者等一次输入输出。"

她伸手把左边那份压着批注的稿子翻到卷角的那页，又合上。

"换手的时候，得先记下我改到哪儿了。哪一页、哪一行、刚才那句改了一半。"她在白板空白处画了一条短链子：

**A 执行 → 存 A 的状态 → 恢复 B 的状态 → B 执行**

"存的是执行位置、寄存器里的那些值。回来的时候再放回去，它就从断掉的那句接着写。"她的语速比刚才快了一截，眼睛盯着那条链子，"不存，就接不上——所以不能说它一定从开头重跑，是接不上，是状态丢了。这两个不是一回事。"

话到这儿，她忽然意识到自己一口气说了不少。声音低下去。

"……嗯。就是这样。"

她把笔搁回槽里，退开半步，两手交叠在身前。台灯的光还落在那两份稿子中间的空隙上。安静了几秒，她才又开口，比刚才小声，但句子是完整的：

"接得上这件事，算是解决了。可是——如果 A 一直不肯交出来呢？它就一直算，不停，也不主动喊我。"她看了一眼白板上那条链子，"那 B 还有机会吗？"

### 第 3 轮

**测试者：**
没有，A 一直算下去的话，B 可能一直等不到。操作系统要能打断它。

**小鞠（原文）：**

她把你这句话在嘴里过了一遍，点头。

"对。B 就一直等。"她拿起笔，回到白板前，"所以光靠程序自己讲道理是不够的。"

她在那条链子下面新起一块地方写。这次写得慢一点，一笔一画。

**A 一直算，不喊我 —— 谁来打断它？**

**硬件定时器：每隔一段固定的时间，向 CPU 发一次中断**
**→ CPU 强制跳进内核，内核拿回控制权**

"这是硬件做的事。"她笔尖点了点"强制"两个字，"每隔一段就响一次，不需要 A 同意，也不需要 A 配合。程序再专心，也挡不住。"

她停了一下，补上一行小字：

**中断 ≠ 一定换人。内核只是拿到一次决定的机会。**

"它响了，内核醒过来，看一眼：换不换？换谁？——也可能看完决定不换，让 A 继续。"她说，"定时器的用处是'定期有机会'，不是'每次都必须切'。"

然后她把笔换到另一只手，在"中断"旁边画了三条短线。

"进入内核不止这一条路。程序自己发起的，比如系统调用、主动让位——那是它自愿的。异常、设备中断，比如除零、磁盘读完了，这些它不想进也得进。"她指了指那条定时器的线，"定时器的特别之处是它**定期**，而且是唯一一个不挑场合、不看程序脸色的。但它不是唯一的入口。"

她把笔搁下，退开半步，看了一遍整块白板。台灯的光把那些字照得发白。

"还有一件事，不解决它，前面这些都白说。"她忽然转过来看你，视线在你脸上停了一下又移开，"A 是在 CPU 上直接跑的——它跑得很快，因为我们让它直接跑。可它跑的时候，什么都能干吗？"

她伸手，在桌上那份只写了一半的稿子上按了按。

"它想读一个文件，能不能自己伸手去碰磁盘？想改别人的抽屉编号，能不能直接改？"

### 第 4 轮

**测试者：**
不能随便干。应该由硬件限制普通程序的特权操作，它要读文件就得请求操作系统。

**小鞠（原文）：**

"对。"她很快接了一句，然后像是嫌自己太快，把声音收小，"不能随便干。"

她走回白板，在你刚才那段话下面写。

**用户态：普通程序待的地方。只能执行普通指令**
**内核态：操作系统待的地方。特权指令只在这里执行**

**要读文件 → 不能自己碰磁盘 → 发起系统调用 → 陷入内核 → 内核代它做 → 返回用户态**

"读文件这件事，它自己做不到。"她笔尖沿着箭头走了一遍，"它只能开口要——这个'要'就是系统调用。CPU 从用户态切到内核态，内核把这件事做完，再切回去，它接着往下跑。"

她把笔停了一下，像是在想要不要补后面这句。

"不过——"她转过来，"刚才说的是'特权指令'。有件事它不用特权指令也干不成，得说清楚。"

她在白板边上另起一小块。

**普通读内存指令，不是特权指令**
**拦住它的是：地址翻译 + 硬件保护检查**

"它想读别人的内存，用的还是那条普通指令。拦住它的不是'用户态'这三个字，是硬件在翻译地址的时候发现这个地址不属于它，直接拦下来。"她说，"用户态/内核态管的是'特权操作'，内存隔离是另一套东西。这两件别混。"

她把笔搁回槽里，退开半步，看了一遍整块板子。台灯的光照得那些字有点晃眼。

然后她又拿起笔。这次没有先说话，直接从白板左端画起一条横线。

"我把刚才讲的连起来走一遍。"

**A 执行 → 定时器中断 → 内核保存 A、恢复 B → B 执行 → B 读文件（系统调用）→ B 等 → 内核恢复 A → A 继续**

她画得很慢，每一段都停一下。

"浏览器 A 在算。定时器响了，内核拿到一次机会。它决定换人，把 A 的位置和寄存器存起来，恢复音乐播放器 B 上次存的那份。B 接着跑。"

笔尖移到中段。

"B 要读文件，发起系统调用进内核。这次读取要等——磁盘没那么快。B 这时候干不了活了。"

笔尖停在"B 等"那个字上。

"然后内核把 A 恢复回来，A 从它断掉的地方接着算。"

她放下笔，退开。安静了几秒，才开口，声音不大：

"这里我想问你一个——B 在等文件的时候，它为什么不让 B 继续占着 CPU 转圈等？"
