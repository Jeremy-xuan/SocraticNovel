# AGENTS.md — SocraticNovel（仓库入口）

> **本文件是仓库级入口。** 具体某个教室的指令在**那个教室目录里的 `AGENTS.md`**（越靠下的越具体）。

## 这个仓库是什么

**SocraticNovel** —— 一套"把教材变成属于你的课"的开源系统。形态是**一个文件夹的 markdown**：角色 / 教学法 / 教材 / 课程表 / 故事线 / 状态笔记本。把它交给支持文件读写的 AI，AI 就会扮演故事里的老师，用**苏格拉底式提问**教一门课。

- **生成器**：`META_PROMPT.md`（当前 **v2.3**，六层结构标准）
- **现成的教室**：`classrooms/` —— 目前有 **`cs-os`**（操作系统，14 讲）
- **界面模板**：`templates/wechat-chat.html`（微信聊天界面，数据驱动，课后更新）
- **参考实现**：`AP_Physics_EM/`（AP 物理电磁学，最早的教室）

## 想上课 / 测试？

🔴 **把工作目录切到具体教室目录再启动**：

```
cd classrooms/cs-os
# 然后在这个目录里启动你的 AI CLI，说"开始吧"
```

`classrooms/cs-os/AGENTS.md` 是那个教室的完整入口（**六层加载**：常驻／启动／**纪律层**／情境／状态／锚定）。**不要在仓库根目录直接开课**——那样只会读到本文件。

## 目录约定

| 路径 | 是什么 |
|---|---|
| `classrooms/<教室名>/` | 一个教室的完整文件系统（入口 = 该目录的 `AGENTS.md`） |
| `classrooms/<教室名>/_anchor.md` | 🔴 **纪律层**：每轮课前必读，落在"历史之后" |
| `classrooms/<教室名>/world/metaphor.md` | 隐喻系统（必须写"这个类比在哪里不成立"） |
| `templates/` | 可复用的界面模板 |
| `META_PROMPT.md` | 生成新教室的引擎 |
| `AP_Physics_EM/` | 参考教室（物理） |

## 红线（改这个仓库时别踩）

1. **叙事不得污染教学正确性**：正式术语与机制以教材为准；每次用完类比必须问"它在哪里不成立"。
2. **教材只链不搬**：有版权的正文不复制进仓库（例：OSTEP 官网明文 *"please just link to them directly"*）；`materials/` 放自写问答版。
3. **人格与教学法分离**：换角色文件不该影响教学法（`system_core.md` / `_anchor.md`）。
4. **加载顺序按"位置 + 频率"**，不按时间——最该遵守的纪律要落在**贴近对话**的位置。
