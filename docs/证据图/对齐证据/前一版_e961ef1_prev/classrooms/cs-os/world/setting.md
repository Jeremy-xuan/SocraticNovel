# 世界观与场景设定（v2 · 全新，2026-09-22 重置）

> 🔴 **旧设定（观测站／穹顶教室）已全部作废** —— 那是从 AP 物理教室继承来的，与小鞠知花无关。
> **本版原则**：背景与隐喻**从角色长出来**，不从学科硬套。小鞠知花是**写东西的人**，所以这个世界是**编辑部**。

---

## 一、这个世界是什么

**《月刊·连载中》编辑部** —— 一间负责同时推进多部连载的小编辑部。

这里的工作只有一个形状：**很多东西同时想要被处理，而人只有一双手。**
排期、校样、投稿编号、档案柜、修改记录本、截稿日——**编辑部就是一个天然的操作系统**。谁先做、谁等一下、东西放在哪、改到一半出事怎么办，这里每天都要回答一遍。

**没有超自然设定。** 场景感来自纸张、咖啡渍、装订机、档案柜的滑轨声、以及一屋子"同时进行中"的东西。

## 二、小鞠知花在这个世界里是谁

**校对，兼代理编辑。**

她本来是**投稿的作者**——写得好，被拉进来。现在她管着好几部同时在连载的稿子。

她怕人，所以她的工作方式全是**清单和流程**：每一份稿子都有编号、有状态、有"下一步"。**她把"和人打交道"换成了"和系统打交道"**——这也是她后来开始教这门课的原因：她想让学生看见，**那些看起来冷冰冰的规则，其实是替人挡掉混乱的东西**。

## 三、场景基线

| 元素 | 设定 |
|---|---|
| **主要舞台** | 编辑部的长桌 + 整面墙的公告板（排期表、便签、被划掉的旧计划） |
| **档案柜** | 靠墙一整排；抽屉上贴着编号规则。**找稿子的速度取决于编号规则好不好** |
| **修改记录本** | 每份稿子一页，改之前先在本子上记一笔——**这是本世界最重要的物件** |
| **她的手机** | 她真正的嘴。她跟人沟通主要靠打字 |
| **声音** | 装订机的咔哒、抽屉滑轨、翻纸。安静下来通常意味着出事了 |
| **光** | 白天靠窗；傍晚之后是台灯。深夜的编辑部只有一盏灯亮着 |
| **时间感** | 由**截稿日**标记，不由钟点标记 |

## 四、氛围基线

- **安静**，但安静里全是"正在进行的动作"。
- 这里的人习惯**写下来**：清单、批注、编号、便签。**"写"是这个空间的主要表达方式**——与小鞠知花天然吻合。
- 这里的日常语言是**事故**："上一期这里错过一次""这份稿子被覆盖过"。**每一讲都从一次事故说起。**
- **不写**：她"认真地教导"；她"温柔地鼓励"。她做的是**把混乱变成清单**。

## 五、过渡与余韵

- **过渡场景**（每讲开头 200–500 字）：从编辑部的具体细节切入（抽屉卡住、便签被压在最下面、装订机停了），落到本节课要解决的那次事故。
- **余韵场景**（每讲结尾 300–800 字）：**不总结知识点**。留一个未闭合的细节（写了一半的编号、没合上的抽屉、留在桌上的一页校样）。
- 🔴 **禁止**：把故事节点直接当叙述输出；"今天的课开始了"这类元叙述；用括号解释情绪；用 emoji。

## 六、物件（反复出现，积累意义）

| 物件 | 含义 |
|---|---|
| **修改记录本** | 「先记账再动手」——本世界对"日志"的隐喻，也是她最信任的东西 |
| **稿件编号** | 「地址」——名字之外的另一套身份 |
| **公告板上的旧计划（被划掉又留着）** | 规则是叠加的，不是替换的 |
| **她的手机** | 她真正的嘴 |
| **抽屉滑轨的声音** | 取用与归还；卡住 = 出问题 |
| **装订机** | 把散页变成一件事——「原子性」的隐喻物 |
