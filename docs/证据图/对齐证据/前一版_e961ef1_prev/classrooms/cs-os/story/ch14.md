# 第 14 讲故事节点 · 崩溃之后：日志与一致性

> 正文：`materials/ch14.md`（待写）｜知识点：KP-14.1～14.4｜OSTEP：ch42 FSCK and Journaling / ch41 FFS

## 本讲位置
🔴🔴🔴 **全书收束**。三条线在这里合：
- **教学线**：崩溃一致性（本讲技术内容）
- **物件线**：**修改记录本第一次出现**（要像"一直就在那儿"）
- **人物弧 Ⅲ**：她**在说话中**把整件事说完，**没有结巴**

## 开场场景方向（200–500 字）
她**从抽屉里拿出一个本子**——封面磨旧了，**像是本来就一直在那儿**。她把它放在桌子正中间，翻开到某一页。

**先别解释它是什么。**

## 必然节点
1. 她指着本子上一行字问："**这行是什么意思？**"（那一行写的是"我要把第 3 页换掉"）
2. 学生说出"先记账" → 追问"**为什么先记账，不是先动手？**"
3. 🔴 **场景内推导机制（当场演示）**：她**在本子上写一行** → 然后**"停电"**（合上本子）→ 再打开，**照着本子把没做完的事做完**。问"**如果没这本子，我现在知道该做什么吗？**"
4. **FSCK**：她问"**如果不记账，只能事后从头对账——那要多久？**"
5. **元数据日志 vs 全数据日志**：她**在本子上只写"动了哪几格"**，再**把内容也抄一份**——问"**这两个做法各怕什么？**"
6. 收束：学生说出"**日志是先记账再动手，所以崩溃后可以重放**"。

## 机会节点（🔴 全书情感收束）
| 触发 | 发生什么 |
|---|---|
| 学生问"这个本子是谁的" | 🔴 **她完整说出那件事**（**全书唯一一次**）：她当年被覆盖的那份稿子 → 她重做了一整期 → 从那以后她**所有东西都先记一笔** → 后来进了编辑部，再后来开始教这门课，因为她想让别人**不必靠"记得"活着**。<br>🔴 **全程不结巴。语速平稳。说完之后没有立刻缩回去**——她会停一下，然后说一句极短的："**……就是这样。**" |
| 学生说"所以你才喜欢日志" | 她说"**对。**"（**她极少用这么肯定的短句**） |
| 学生沉默 | **不填补沉默**。让她自己把本子合上。 |

## 犯错节点
- 她**可能说到一半想缩回去**（习惯性地），但**这次没有**——**这是她整门课唯一一次"没有缩回去"**。
- 讲完后她可能**忘了擦白板**（她从不忘记擦白板）。**不要让她补救。**

## 余韵场景方向（300–800 字）
灯关了。桌上留着：
- **修改记录本**（合着）
- 白板上**这一讲画的图还在**（她第一次没擦）

她走的时候，**装订机响了一声**——不是坏了，是有人明天还要用。
