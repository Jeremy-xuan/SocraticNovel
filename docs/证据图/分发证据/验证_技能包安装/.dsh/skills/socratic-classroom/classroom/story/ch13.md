# 第 13 讲故事节点 · 文件与目录

> 正文：`materials/ch13.md`（已落盘 2026-09-24）｜知识点：KP-13.1～13.4｜OSTEP：ch39 Files and Directories / ch40 FS Implementation

## 本讲位置
Ⅳ 段开始。技术线转向"东西存在哪"，情绪线为第 14 讲蓄力。

## 开场场景方向（200–500 字）
她把**一张编号卡**放在桌上。卡上**没有标题**，只有编号。她问："**你怎么找到它？**"

## 场景节点

> 叙事动作服务人物弧；其中的问句是可用台词，不是逐项执行的题单。教师可直接讲清必要事实，学生已理解时跳过问句并继续。技术问题要说出真实对象，道具只辅助演示。
1. 学生说"查目录" → 追问"**目录里存的是什么？**"→ 逼到"**名字 → 编号** 的映射"。
2. **inode 不存文件名**：她**把编号卡翻过来**——背面只有"改过几次、多大、第几版"，**没有标题**。问"**为什么不写在卡上？**"
3. **一次 write 的路径**：她**从稿纸 → 校对 → 登记 → 进档案柜**走一遍（真的走），配合白板讲清各步对应的真实文件系统操作；遇到学生混淆的位置再停下讨论。
4. **文件描述符**：她指着桌角那排"当前打开着的稿子"——"**这个序号是什么？**"
5. 收束：检查学生能否解释目录的名字映射，以及一次写入涉及哪些步骤。

## 机会节点
| 触发 | 发生什么 |
|---|---|
| 学生问"改过几次为什么要记" | 她说"**因为有人会问'这版跟上一版差在哪'。**"（接 ch14 的日志） |
| 学生问"编号乱了怎么办" | 她说"**编号不会乱。乱的是人。**"——**她少见的、接近玩笑的一句** |

## 犯错节点
- 她走流程时**可能因为要不停说话而卡住**，会改用**写在白板上**的方式走一遍。

## 余韵场景方向
那张编号卡**正面朝下**留在桌上。

## 暗线种子
- 埋：**"改过几次"**（ch14 回收，接日志）
