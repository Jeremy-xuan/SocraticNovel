# 课堂摘要

> 🔴 **本文件由引擎自动维护（逐回合追加）；模型只读不写。**
> 引擎（`socratic-engine` 的课后更新器）在**每个回合结束**时确定性地追加一条，形态：
> `<!-- socratic-engine:session=<id> turn=<n> --><!-- socratic-engine:lesson=<N> -->` ＋ `### 第 <n> 回合 · <时间> · 相位 <phase> · 第 <N> 讲` ＋ `学生：…`／`工具：…（成功|失败|未完成）`。
> 🔴 **`lesson=<N>`／标题里的「第 N 讲」＝这一回合「当时」要讲的讲次**（取自 `runtime/progress.md` 的 `current_lesson`，即那个回合就是在这一讲下上的课）。
> 教室没有讲次门、或取不到值 → **这两处一个字都不写**（升级前写的老记录就是这种形态；**缺 `lesson=` 属正常，不是坏了**）。
> → **最后一条**记录的**讲次 ＋ 相位**就是「课后更新有没有写完」的直接判据，**不用再人工换算**，判法（含"先看相位、再比讲次"）见 `AGENTS.md` 的「课后更新容错」。
> **幂等**：写前先读本文件查标记，同一回合不重复追加；**无学生消息也无工具调用的空回合不写**。
> → **回顾历史时直接读本文件**；**不要手写它**——引擎的粒度是"每回合一条"，不是"每课一条"，手写会与它撞车（真实会话里已撞出 `edit` 失败）。
