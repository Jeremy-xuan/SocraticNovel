## 5. 本轮踩到的两个通道坑（写给后续）

1. **GitHub REST API 未登录只有 60 次/小时** —— 本轮跑目录核验时用光，之后全部 403/429。绕过办法（本轮实际用的）：
   - README 正文：`https://raw.githubusercontent.com/<owner>/<repo>/<branch>/README.md`
   - 目录树：抓 `https://github.com/<owner>/<repo>/tree/<branch>/<path>` 页面里内嵌的 `<script type="application/json" data-target="react-app.embeddedData">`，取 `payload.codeViewRepoRoute.tree.items`（**仓库根页**）或 `payload.codeViewTreeRoute.tree.items`（**子目录页**，键名不同，容易漏）。
   - jsDelivr 的 `data.jsdelivr.com` 对 >50MB 的仓库直接 403，本轮的 BanG Dream 仓库全部超限 → 不可用。
2. **Steam 连续抓 item 页会 429** —— 需要 10 秒以上间隔；本轮 16 条成功、4 条被限流。
