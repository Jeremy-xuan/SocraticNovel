## §1 `sync-classroom.sh` 的机制与它到底做了什么

### 1.1 源码（全文 25 行，关键部分逐字）

```sh
here=$(CDPATH= cd -- "$(dirname -- "$0")" && pwd)
src=${1:-"$here/../../classrooms/cs-os"}
dst="$here/classroom"

if [ ! -f "$src/classroom.yaml" ]; then
  echo "错误：$src 不是一个教室目录（找不到 classroom.yaml）" >&2
  exit 1
fi

mkdir -p "$dst"
rsync -a --delete "$src/" "$dst/"
echo "已同步：$src -> $dst"
```

### 1.2 机制判读

| 维度 | 事实 |
|---|---|
| 源 / 目标 | 源默认 `$here/../../classrooms/cs-os`（即 `code/classrooms/cs-os`）；目标固定 `$here/classroom`（技能包内） |
| 前置校验 | 源目录必须存在 `classroom.yaml`，否则报错退出 1（防止指错目录把副本清空） |
| 同步语义 | `rsync -a --delete` —— 三条语义必须一起读：<br>① `-a` ＝ `-rlptgoD`：递归 ＋ **保留 mtime／权限／属主**；<br>② `--delete`：**源里删掉的文件在副本里也删掉**（副本不会留孤儿）；<br>③ **没有任何 `--exclude`／白名单**：**整间教室全量覆盖**。 |
| 依赖 | 只用 `rsync`，无第三方依赖（作者自注） |
| 作者声明的联动关系 | "两边不自动联动 —— 每次教室内容更新后跑一次本脚本，包内副本才会跟上" |

**对任务书 ① 里那个假设的回答**：任务书猜"包内可能有意排除某些说明书"。**不成立**——脚本没有任何排除规则，它是**全量镜像**。所以 `接线说明_materials_ch08-14.md` 之所以同步前不在包内，**只是副本停留在它被写出来之前**，不是有意排除。

### 1.3 它本次实际做了什么

```

已同步：/Users/wujunjie/Documents/ChatGPT/大学申请/开源线/DSH定制/code/skills/socratic-classroom/../../classrooms/cs-os -> /Users/wujunjie/Documents/ChatGPT/大学申请/开源线/DSH定制/code/skills/socratic-classroom/classroom
EXIT=0
```

- 包内文件数：**43 → 49**
- 新增 6 个：`materials/ch10–ch14.md`（5）＋ `接线说明_materials_ch08-14.md`（1）
- 内容变更 18 个（§2.2 有全表）
- 同步后 `diff -rq classrooms/cs-os skills/socratic-classroom/classroom` → **EXIT=0，零输出**（两目录完全一致）

### 1.4 🔴 本次实测到的一个取证坑（建议写进长期教训）

`rsync -a` **保留源文件 mtime**，因此被覆盖/新拷进来的文件**带着源文件的旧时间戳**。
→ 用 `find -newermt "<会话开始时刻>"` 反查"我改了哪些文件"会**系统性漏报**：
本次它只报出 **2 个**文件，而 sha256 对照显示实际变了 **24 个**。

**规则**：判"改了哪些文件"**必须用 sha256 逐文件对照**，`mtime` 只能当参考。
（本报告的 §5 全部用 sha256。）
