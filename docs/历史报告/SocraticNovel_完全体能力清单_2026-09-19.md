## §0 核心结论：复用边界画在哪里（🔴 本版最重要的一节）

我把 13 个能力域逐个查了一遍全球开源现状，结论异常清晰：

| 层 | 现状 | 决策 |
|---|---|---|
| **基础设施层**（PDF 解析、多模态渲染、记忆、多模型接口、账号、白板、语音、桌面壳、导出） | 🔴 **全部有 3 万–18 万★ 的成熟项目** | **一律复用，绝不自己写** |
| **教学智能层**（苏格拉底引擎、教材生成、知识点映射、测验、知识图谱） | 🔴 **全球几乎空白** | **必须自研** |
| **叙事耦合层**（教材×故事同源生成、隐喻映射、进度⇄剧情绑定） | 🔴 **全球空白，只有我有** | **必须自研（护城河）** |

**实测证据（搜出来的最高星）**：
- `socratic teaching LLM` → 最高 **1★**
- `textbook generation LLM` → 最高 **3★**
- `AI quiz generator LLM` → 最高 **5★**
- `knowledge graph LLM teaching` → 最高 **0★**
- `SVG diagram generation LLM` → 最高 **1★**
- 而 `AI tutor open source` → 最高 **126★**（`artcc/freelingo`，语言学习，形态不同）

→ 🔴 **一句话：通用的都能拉，没人做的那块不能拉——而没人做的那块恰好就是护城河。**

**同时一条警告**：我前面写的"多提供商 API 工厂""跨平台 Keyring""GitHub OAuth"——**这三个都在重复造轮子**（§1 有现成的）。这就是本轮要解决的问题。

## §4 后面讨论的定案（并入本清单）

### 4.1 定位与护城河
| 层 | 是什么 |
|---|---|
| 🔴 **护城河** | **专属教材生成**（把 $350／4 小时打到接近零） |
| **放大器** | **沉浸式叙事**（易模仿，但和专属教材结合后不可分） |
| **不可复制** | **真实运行过的记录** |
| **不是护城河** | "完整"、"记得你"、"苏格拉底式提问"（都是原文公开内容，已有竞品） |
| **一句话** | **Bloom 给你一个老师，教材是别人的；SocraticNovel 的教材是为你写的，老师是故事里的人。** |

### 4.2 AnimaTutor = 叙事主干（用户已确认"本来就是，基本是移植过来的"）
带来：**Ur-Prompt / Multi-Prompt Design / Pair Prompt** 三个概念；**8 文件架构**（BOOT + 00–07）；🔴 **`03_学科场景机制.md`（六要素 × 五学科的隐喻系统）**；**"连接理由"理论**（"感情不是聊出来的，是做出来的"）；**`04` 的非线性情感里程碑**；**`06/07` 的状态追踪与角色记忆**。

### 4.3 碎片化 × 长期陪伴（五条机制 + 升级阶梯）
1. 记忆是累积的——**把"感受到陪伴"从第 7 次交互压到第 2 次**
2. "一道题 = 章节触发器"降级为"一道题 = 场景片段"
3. 🔴 **碎片化恰恰是连接理由最强的时候**（"我真的不会"是最硬的理由）→ **判据：如果这道题不存在，这次交互还成立吗？成立就是跑偏了**
4. 展示**累积物**，不展示**进度**
5. 用**非线性里程碑**做入口
**升级阶梯**：搞懂一道题 → 识别缺什么 → **一条最小路径（3 节不是 30 节）** → 一门课。**教室不是单节课的替代品，是它的延伸。**

### 4.4 三条红线
① **沉浸是手段，学习是目的**（沉浸单独已被验证没人要：全站最高 1★）② **叙事不能污染教学正确性** ③ **任何"为了沉浸牺牲学习效果"的能力都是错方向**

### 4.5 人群（受众 ≠ 用户）
- **受众线（涨★）**= 把一次课堂变成**可传播单元**；**用户线（做价值）**= 砍门槛
- 砍门槛的优先级：**教室库 > 单节课 > 终点导向 > 优先打"有截止日"的人**（考生/跨考/期中期末 ≫ 成人终身学习者）
- "窄"的根因是**承诺门槛太高**（原文 502 赞同 vs 公开复现者 2 个）

### 4.6 设计定案
- **关系做"基于文字的系统"，不做好感度数值；知识掌握绝不数值化**
- **剧情/关系可分支；知识路径不分支**（默认无选择，分支作为可选层）
- **沉浸的度 = 每课后状态更新能全部自动完成、且不撞 context 上限**
