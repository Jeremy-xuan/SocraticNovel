### 1.2 🔴 由此得出的结论（这条决定"改成什么形态"）

**引擎里没有"每次相位切换注入一次"这种模式。** `every: phase` 的真实语义是：

> **逐回合按当前相位裁决**——本回合相位落在门的允许集合里 → 注入；不在 → 不注入。**它不记账、不判"切换"**。

所以任务书里那句"语义＝课堂每换一个阶段，教学检查跟着来一次"**在引擎里没有直接对应的实现**；能落地的是它的两种近似：

| 写法 | 引擎里的实际效果 | 评价 |
|---|---|---|
| `every: phase`（**不写** `phase:` 字段） | 相位门恒开〔A05〕 → **每轮都注入**，与相位**完全无关** | ❌ **不能用**：这正是本项目禁止的"看起来配了门、其实门恒开"——一个把 `on_demand` 换成 `turn` 等价物的假门 |
| `every: phase` ＋ `phase: {...}` | **真实的相位限制**：只有当前相位落在集合里才注入 | ✅ 按引擎要求的形态写 |

→ **按引擎要求的形态写＝必须带 `phase:` 字段**。这是本轮唯一"按源码而不是按措辞"做的判断。

### 1.3 改后的值

```yaml

    layer: anchor
    position: { target: chat, depth: 0 }
    frequency: { every: phase }        # ← 原来是 { every: on_demand }（死门）
    phase: { except: [open] }          # ← 新增：六个相位里只有开场不放行
    wrap: { style: system-reminder }

```
〔A16〕（值本身）｜〔A18〕（块头注释）

**为什么是"除开场外"**（不是随手挑一个集合）：

1. **六个相位里唯一"四问都无处着落"的就是 `open`**——教学检查问的是「学生是否知道我刚问的是什么／我有没有回应他的真实想法／有没有顺势推进／核心事实有没有说得比教材更确定」，这四问都要求**已经有师生往来**；开场相位按教室自己的定义是"开场、把本讲的核心疑问摆出来"，还没有可校准的往来。
2. **不设任何回合配额**：门的判据是相位，不是"每 N 轮"——`n_turns` 那条机械配额没有再回来。
3. **强度与官方六层表一致**：教室自己的六层表把 ② 纪律层的频率写成「每轮」〔A24〕，`_anchor.md` 的四段都是这层的内容；把 ④ 段挂到相位门上、六个相位里放行五个，既保住了"每轮在场"的强度，又让它可以随相位收放（要收窄只改这一行）。

## 3. ② 新纪律：正文里不许出现"工具编排的打算"

### 3.1 原文与位置

加在 `_anchor.md`「本课不许违反项（每讲更新）」里，**紧挨**既有的那条格式禁令（"不用括号旁白／`<sub>`／章节状态标签"）之后〔A21〕：

> - 🔴 **面向学生的正文里只出现课堂内容**：不要把“我接下来要调什么工具”“按哪条纪律”“先讲后画”这类**编排打算、待办或自我提醒**写进正文（含英文草稿）。工具照常调，只是不必在正文里交代为什么调。

**为什么这么短、为什么只管这一件**：
- 纪律层**每轮贴尾**，体量有硬约束 → 一条一句，不展开；
- 它**只管"可见正文里写什么"**这一件事，**不冻结任何教学行为**（工具该调还调、该先讲后画还先讲后画）——末句"工具照常调，只是不必在正文里交代为什么调"就是防这条被读成"少调工具"。

### 3.2 与既有条目的关系（同类、紧挨）

同一节里已有三类"面向学生的正文里不许出现什么"的禁令：**括号旁白／`<sub>`／章节状态标签**、"引擎语言不许向学生播报"、"白板内容只能画出来"。本条与它们是**同一类**（可见正文的禁令），所以放在**第一条格式禁令的下一行**——生成点最近、读起来是一组。

**事实依据**（上一轮真会话）：`assistant/message` 的一条**学生可见正文**块里混进了 248 字符英文编排打算（如 *"I need to now call the animation. But per 「先讲后画」… Let me write message B's ending…"*），它**引用了引擎纪律段的原词**——严格说引擎语言进过一次学生可见正文；**2 次会话里出现 1 次**，只能报"观察到一次"。

### 3.3 两处都写（照既有口径）

`system_core.md` 的「课中」那一条（既有白板／动画／引擎语言三种渠道纪律的同一段）补了同款一句〔A22〕：
