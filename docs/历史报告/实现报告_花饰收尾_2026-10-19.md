## 一、三处不足修复与前后数值对比

### 1. 六行选项端饰「齿链」感消除（重塑为活跃态织边）
- **原问题**：原 `.oe` 的 `opacity` 为 `0.34`，六行紧排（`.opts` gap 0.55vh，端饰高 4.7vh），端饰在垂直方向几乎头尾相接，导致左侧和右侧各自呈现出一排密集的垂直小齿（类似机械拉链齿轮链），视觉压迫感重。
- **改动策略**：
  1. 默认未选态（及 disabled 态）设为透明（`opacity: 0`），彻底切断拉链齿链感；
  2. 缩小端饰尺寸与线宽，使其更轻盈精致，仅作为活跃态（`cur` 键盘焦点、`:hover` 悬浮、`picked` / `picked sent` 已选中）的两翼织边徽饰浮现。
- **数值变化对比**：
  - `.oe` 尺寸：`width: 3.05vh; height: 4.7vh; margin-top: -2.35vh;` → **`width: 2.65vh; height: 4.1vh; margin-top: -2.05vh;`**
  - `.oe.l / .oe.r` 水平间距：`left: -3.35vh; right: -3.35vh;` → **`left: -2.95vh; right: -2.95vh;`**
  - 线宽：外柱 2.0px → **1.8px**，内柱 1.2px → **1.1px**，卷须 1.5px → **1.4px**
  - 默认透明度：`opacity: 0.34;` → **`opacity: 0;`**
  - 活跃态响应保持：
    - `:hover`: `opacity: 0.88`
    - `.cur`: `opacity: 1; color: var(--vermilion);`
    - `.picked`: `opacity: 0.9; color: rgba(224,146,28,.95);`
    - `.picked.sent`: `opacity: 0.95;`

### 2. 四角卷草偏弱增强
- **原问题**：原 `.corner` 尺寸为 6.4vh、opacity 为 0.62，线宽偏细，且无立体微投影。在左上角明亮的白窗帘与晨光夕阳映衬下轮廓被冲淡吞没，右下角亦存在感单薄，无法起到古典画框包角的稳固装帧作用。
- **改动策略**：
  1. 放大构件体量，外扩贴合角隅；
  2. 加粗内外臂与卷须线宽，提升透明度；
  3. 引入精细深色微投影滤镜，确保在任何高亮或低暗背景下都能清晰剥离。
- **数值变化对比**：
  - 尺寸：`width: 6.4vh; height: 6.4vh;` → **`width: 8.8vh; height: 8.8vh;`**（尺寸放大 37.5%）
  - 边距：`left/top/right/bottom: 2.6vh;` → **`2.2vh;`**
  - 透明度：`opacity: .62;` → **`opacity: .88;`**（提升 41.9%）
  - 线宽：外框臂 2.0px → **2.2px**，内框臂 1.1px（opacity .55）→ **1.2px（opacity .65）**，双卷须 1.5px → **1.65px**
  - 边缘投影：新增 **`filter: drop-shadow(0 1px 3px rgba(20,16,12,.52));`**

### 3. 正文与选项间补齐并接入「叶形分隔带」（Leaf Band）
- **原问题**：原 `ornaments/build-constants.mjs` 中未导出贝塞尔化的 `leafBand()` 常量，`lib/client.js` 中正文与分节抬头 `.orn` 直接相邻，纵向缺乏视觉锚点与结构转承。
- **改动策略**：
  1. 在 `ornaments/build-constants.mjs` 中将 `leafBand()` 的密采样折线（一柳叶居中 + 两侧波浪蔓延）转为 Catmull-Rom 三次平滑贝塞尔曲线，导出常量 `LEAF_BAND_L` 与 `LEAF_BAND_R`；
  2. 在 `lib/client.js` 中以纯 `React.createElement` 封装构件 `ORN_LEAF_BAND`，由居中柳叶、中脉、双侧波浪及两侧淡化发丝线 `sep-line` 组成；
  3. 分隔带采用 `--accent` 铁锈赭色（`#B84A1C`），与金色的分节抬头（`--gilt`）形成典雅的冷暖微错落层次；
  4. 协同微调了 `.leaf-sep`、`.orn` 与 `.opts` 的垂直 margin/gap，使正文与选项区域节奏舒展、呼吸匀称。
- **具体数值**：
  - 叶形构件：`viewBox="0 0 160 26"`，尺寸 `width: 12vh; height: 1.95vh;`
  - 叶形中脉：`stroke-width: 1px; opacity: 0.6;`
  - 两侧发丝线：`flex: 1; height: 1px; background: linear-gradient(90deg, transparent, rgba(184,74,28,.30), transparent);`
  - 外边距与间隙：`.leaf-sep` margin `0.8vh 0 0.5vh`；`.orn` margin-bottom 从 1.85vh 微调为 `0.8vh`；`.opts` gap 从 0.55vh 优化为 `0.45vh`。

## 四、「我认为还可以更好但没做」的清单

1. **多选项时纸带高度的自适应**：
   当前纸带 `.band` 为固定高度 `48vh`，扣除底部 composer 11vh 后可用高度为约 37vh。当选项达到 6 行时，卡片区（约 29.5vh）加分隔带与抬头会挤占大部分垂直空间，导致在贴底布局下前序历史消息滚至视口外。后续可考虑当 `options.length >= 5` 时，动态为 `.band` 增加类名将高度平滑拉升至 `52vh~54vh`，留出更宽裕的正文阅读空间。
2. **选项卡片 hover 微动效的联动**：
   目前卡片在 `:hover` 时有 `translateX(3px)`，端饰则靠 `opacity` 渐显。如果端饰在浮现的同时带一个微小反向舒展动画（例如左侧端饰向左微移 2px，右侧端饰向右微移 2px，配合弹性缓动），会更具类似纸牌/徽章羽翼展开的灵动仪式感。
3. **超宽屏与极窄屏下的比例约束**：
   目前装饰构件采用 `vh` 单位，保证在 16:9 / 16:10 常用分辨率下视觉比例严谨统一。若在 21:9 超宽屏或竖屏场景下使用，可进一步增加基于媒体查询的横向约束，防止构件在极窄视口下产生字间距拥挤。
