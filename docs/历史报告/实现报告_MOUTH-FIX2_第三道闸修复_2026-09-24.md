## 一 · ① 补全区判据：改成了什么

### 1.1 改前 / 改后

| 项 | 改前 | 改后 |
|---|---|---|
| 算式 | `hole = others & box & (~m)`，其中 `others` = **所有其它部件的并集**〔A26〕 | `hole = others & box & (~m)`，其中 `others` = **只取绘制序更高的部件**〔A26〕〔A25〕 |
| 判据常量 | 无（硬编码"全部"） | `OCCLUSION_DIRECTION = 'above'`〔A01〕；由 `--hole-mode` 暴露（`above` / `all`）〔A02〕 |
| 判据不成立时 | **静默产出错层** | **抛 `SystemExit(6)`，不产出层**〔A03〕 |
| 可审计 | 无 | `result.json` 落盘 `occlusion_direction` / `draw_order_used` / `occluder_report`〔A04〕〔A05〕 |

**依据（一句话）**：SAM 给的是**可见像素**，而"可见"本身就带着"谁盖住谁"的信息——
**画在 P 下面的部件不可能遮挡 P**。原式把"画在下面的脸"当成"盖住嘴的东西"，
LaMa 于是把嘴外接框里的脸重画成嘴 ⇒ 嘴层从 918 px 膨胀到 1,530 px（×1.667）〔A06〕；
同一个错也让 `hair` 从 136,917 px 膨胀到 204,899 px（×1.497）〔A07〕，
它接成 `hair_front` 之后 **100% 盖住嘴**（1530/1530）⇒ 真渲染器 0 px。

### 1.2 🔴 判据不成立时**不许静默降级** —— 三条件硬检查

`check_occlusion_direction(units, direction, order_mode)`〔A03〕在跑之前做三项检查，
任一不成立就 `raise SystemExit(6)`，**并且把后果写进报错正文**：

1. `--hole-mode` 只能是 `above`；`all` **仅在 `--order legacy`（复现修前行为的对照实验）时才被允许**
   —— `all` 配修后的表一律报错（那种组合既没有旧行为的可解释性，又丢掉了判据）。
2. 每个部件都必须能在表里查到绘制序，否则"算不出补全区"。
3. 序表里至少要有两个不同的值，否则 `above` 分不出遮挡物。

**`SystemExit(6)` 的后果说清**：**这一跑不会产出层**——因为"用哪一半部件当遮挡物"
直接决定层 alpha 的大小，判据不成立时产出的层是**不可信的**。

**这条自检不是摆设，它本轮真的响过一次**：把 `handwear_l` / `handwear_r` 这类
**双侧拆分后的名字**直接丢进序表查（表里只有基名 `handwear`），自检立刻报
`[FATAL] 以下部件在 DRAW_ORDER 里没有绘制序，算不出补全区：['handwear_l', 'handwear_r']`〔A08〕，
退出码 6、零层产出。修法是 `order_for()` 先剥 `_l` / `_r` 后缀再查表〔A09〕。

## 三 · ① 前后发拆分：**拆开了**

### 3.1 拆没拆开

🔴 **拆开了，但要如实说清"拆到什么程度"**：拆的是**可见像素的归属**，不是"把后发藏在脸后面的那部分也重建出来"。

| 图 | SAM `hair`（合并） | → `hair_front` | → `hair_back` |
|---|---|---|---|
| `ourasset` | 136,917 px | **11,308 px**〔A12〕 | 125,609 px |
| `test1` | 25,546 px | **2,623 px** | 22,923 px |

**判据**（`_hair_split`〔A13〕，几何判据，不是深度模型）：

```
脸区域 = 脸掩码 → 形态学闭运算（31 px 椭圆核，填掉五官留下的洞）→ 外扩 6 px
hair_front = hair ∩ 脸区域        （脸区域内的头发可见像素 ⇒ 只可能是画在脸上面的那部分）
hair_back  = hair ∩ ¬脸区域
```
常量：`HAIR_FACE_GROW = 6`〔A14〕、`HAIR_FACE_CLOSE_KERNEL = 31`〔A15〕。

**为什么这个判据成立**：SAM 给的是**可见**像素。头发在**脸区域之内**还能被看见，
只可能是**画在脸上面的那部分头发**（刘海/鬓发）；落在脸区域外的，只可能是**没被脸盖住的后发**。

**关键验证（前发不碰五官）**〔A16〕〔A17〕：

| 图 | 前发 ∩ 嘴 | 前发 ∩ 鼻 | 前发 ∩ 眼 |
|---|---|---|---|
| `ourasset` | **0 px** | **0 px** | 23 px |
| `test1` | **0 px** | （无鼻层） | 148 px |

**前发在嘴与鼻上都是 0 px** ⇒ 它不遮挡嘴/鼻。眼上那 23 px / 148 px 是**刘海压在眼睛上沿**，
这是这张立绘本来的画法（不是错）。

### 3.2 🔴 如实说：前后发**仍未拆**的部分

- **"被脸挡住的后发"没有重建**：`hair_back` 拿到的是 SAM 可见掩码落在脸区域外的部分，
  脸后面的那一段头发**本来就没被 SAM 看见**，本轮的几何判据**不重建它**。
  后果：后发在脸两侧的**内侧边缘**会缺一小条（被脸盖住，静止时看不出；
  头一转、后发跟着动时可能露边）。**要补这一条需要深度估计（重型路线），本轮没做。**
- **前后发的分界线是几何的、不是深度的**：脸区域外扩 6 px 是手调值，
  它不是"头发真正的前后分界"。对这两张图它工作正常（前发 0 px 落在嘴/鼻上），
  但**换一张图必须重新验证**——这一点写进 §7 未做到项。
- **一个真实的降级路径已实现且会响亮报出**：若前发为空（脸区域完全盖住头发），
  `_hair_split` 会把整块 `hair` 按**后发**处理并打印
  `[警告] 前发为空 → 整块 hair 按后发处理（刘海会丢失，但不会盖住脸）`〔A18〕
  ——**宁可丢刘海，也不让整块跑到最上盖脸**。

### 3.3 🔴 为什么"补全判据"和"前后发拆分"缺一不可（消融实证）

| 配置 | `hair` 层 alpha | 嘴层 | 真渲染器 0→1 |
|---|---|---|---|
| 修前（原判据 + 原序表 + 不拆） | 204,899 px | 1,530 px（膨胀） | **0 px** |
| 只修判据、**不拆**前后发（`ablate_nosplit_ourasset`） | 204,899 px | 918 px（不膨胀 ✅） | **0 px** |
| 只拆前后发、不修判据 | （等价于修前） | — | 0 px（上一轮已证） |
| **两件都做（本轮）** | 前发 11,308 / 后发 125,609 | 918 px | ✅ **291 px** |

**读法**：第二行是关键——**补全判据修好之后嘴层已经不膨胀了（918 px，×1.0）**，
但因为 `hair` 仍是**一整块**、仍然被接到最上层，嘴照样被盖住 ⇒ **0 px**。
所以"只修判据"不够，必须同时拆开前后发。**这两个修法各自都是必要条件，合起来才充分。**

〔A35〕〔A36〕〔A37〕〔A38〕

**新增判据的准确表述**：在**不驱动任何参数**的前提下，把本模型画面与
「**同一套层集、只去掉嘴层**」的对照模型画面逐像素比，
要求 **落在「嘴窗口」之外的差异像素数 ≤ 20 px**。

### 6.2 🔴 为什么判据不是"差异必须为 0"（这是本轮踩到并修掉的一个设计错误）

**第一版我写成了"差异必须为 0"，跑出来是 447 px、判红 —— 但那是错的判据。**
理由：本模型比对照模型**多一个嘴层**，静止帧下嘴本身就该被画出来
（918 px 的嘴 ⇒ 截图里 447 px 的差异）。**"差异为 0"会把"嘴正常显示"判成污染。**

真正要抓的是「**差异跑到嘴以外**」：上一轮那个坏嘴层的表现是**被 LaMA 重画成整张脸的内容**，
它在静止帧里会让画面在**远离嘴的地方**与无嘴层模型不同。
所以判据改成：**嘴窗口之外**的差异像素数 ≤ 20。

**嘴窗口怎么算**（`mouth_screen_region`〔A39〕）：
嘴层 alpha 的**模型坐标 bbox** × `截图宽 / 画布宽`，再外扩 2% 边长。
实测比例 `720 / 1024 = 0.703125`，与"嘴层 bbox 宽 44 px → 截图差异 bbox 宽 31 px"吻合。

| 模型 | 嘴层 bbox（模型坐标） | 嘴窗口（截图坐标） | 静止帧差异 | **其中落在窗口外** | 判定 |
|---|---|---|---|---|---|
| `fix2_ourasset` | y 539–565 / x 490–533 | **[330, 364, 389, 411]** | 447 px | ✅ **0 px** | ✅ 合格 |
| `fix2_test1` | y 184–186 / x 469–477 | **[349, 128, 384, 158]** | 0 px | ✅ **0 px** | ✅ 合格 |

**这条判据的能力**：它**不需要驱动任何参数**就能抓出坏层（与主判据正交），
而且它抓的是"**嘴层把内容画到了嘴以外**"这一类错误 —— 正是上一轮那个坏嘴层的形状。

**它的边界（如实说）**：如果坏嘴层**恰好只在嘴的位置上画错东西**（比如嘴区里多出一块色斑），
这条判据抓不到。真正兜住那一类的是 **`RGB 不一致 = 0`** 那条（§4.3）。
**两条判据合起来才覆盖得住**，单靠任何一条都有盲区。

### 6.3 过闸判据与退出码

```

```
〔A40〕

- 退出码：**0 = 过闸；1 = 报红；2 = 环境/装载失败**（探测不到数，**不当"过"**）〔A41〕。
