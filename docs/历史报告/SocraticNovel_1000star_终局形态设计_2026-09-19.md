## §0 先问：谁会 star？为什么 star？

★ 不是"评价"，是**一个具体的人在一个具体时刻做的动作**。所以先分清谁会点：

| 谁 | 他在什么时刻点 ★ | 他要什么 |
|---|---|---|
| **A · 好奇的过路人** | 刷到一句话/一段视频，"这什么？" | **5 分钟内看到东西**——不是读 24KB README |
| **B · 想造自己系统的人** | 看完 demo 想"我也想要一个化学老师" | **一条可复制的路**（模板 + 指令，别让我想） |
| **C · 教育从业者 / 老师 / 家长** | 想拿去真上课 | **一个能直接用的成品**，不是"你自己生成" |
| **D · AI / 技术圈的人** | 判断"这个做得巧不巧" | **可读的设计 + 能跑的代码** |

🔴 **关键**：这四类人**要的东西不一样**。现在的仓库只服务 B（而且要 B 先读 24KB 才入门）→ **A、C、D 全部漏掉**。1,000★ 的仓库必须**四个入口都通**。

## §1 一句话：30 天后它应该是「一个会记住你的 AI 老师」，不是「一个框架生成器」

这是本文最重要的一条重构。

| | 现在（生成器） | 30 天后（运行时） |
|---|---|---|
| 它是什么 | `META_PROMPT` —— 一个**生成器**，回答 AI 的问题，生成 50+ 个文件 | **一个教师运行时** —— 已经在跑、已经有课、已经记得你上到第几课 |
| 用户要先做什么 | 先投入（读完、回答一堆问题、生成、调试） | **什么都不用做，直接进第一课** |
| 价值什么时候产生 | **用户投入之后** | **打开就有** |

🔴 **为什么这条是决定性的**：**★ 发生在"投入之前"。** 一个要求用户先投入半小时才能看到价值的东西，**天然难涨星**——不是因为不好，而是因为**它把成本放在了收益前面**。
→ 所以 1,000★ 版本的核心动作是：**把"生成你自己的系统"从"入口"降级成"进阶功能"**。

**它唯一不可被替代的那句话**（1,000★ 的项目都有一句"只有它能做的事"）：
> **别的 AI 教学项目教你知识；这一个陪你上完一个学期，并且记得你。**

## §2 实测：1,000★ 的同赛道项目，物理形态长什么样

【实测】四个可比项目（`ChatTutor` 1,316★／`agents-from-scratch` 1,018★／`human-skill-tree` 557★／`HKUDS/DeepTutor` 40,093★）的共同点：

| # | 共同特征 | 实测依据 |
|---|---|---|
| 1 | **有可点的在线站点** | ChatTutor：`homepage = https://chattutor.app`；human-skill-tree：`humanskilltree.yechengzhang.com` |
| 2 | **有正式软件许可证，GitHub 能识别** | ChatTutor = **AGPL-3.0**；human-skill-tree = **AGPL-3.0**（不是 `NOASSERTION`） |
| 3 | **有语言、有能跑的代码** | ChatTutor = Vue（7.2MB）；human-skill-tree = TypeScript |
| 4 | **卖点是"看得见的交互"，不是理念** | ChatTutor 的 Features 只有两项：**Math Canvas（数学画布）／Mindmap（思维导图）**；human-skill-tree：33 个 skills／800+ 学科 |

| 6 | **有"社会证明"的可视元素** | ChatTutor README 末尾有 **Star History 图**；human-skill-tree 有 **visitor badge** |

**→ 六条"1,000★ 的物理形态"。你现在**（【实测】）：`language = null`（没有一行代码）／`license = NOASSERTION`／**没有在线站点**／README **0 张图**／上手要先读 24KB／无任何社会证明元素。**六条缺六条。**

## §3 30 天后的 SocraticNovel：五个功能

### F1 · 一条命令开始上课
- **是什么**：`npx socratic-novel start`（或 `init --classroom ap-physics`）→ 自动装好文件、**自动写好 `CLAUDE.md`**、校验文件齐全 → 打印一句"现在对 Claude Code 说：开始吧"。
- **解决谁的时刻**：A 类（好奇）与 B 类（想造）——**把"读 24KB 才知道怎么用"压缩成一条命令**。
- **现状差多远**：🔴 现在 `language = null`，**没有 CLI**；而且【实测】fork 的人第一件事就是**自己补 `CLAUDE.md`**（shentianming1994 的提交）→ 入口是真的断的。
- **顺带解决**：`language` 不再是 null → 可被 `language:` 搜到、可进 Trending 语言榜（【推断】）、以及"它到底算不算 software"的定性问题。

### F2 · 开箱即用的教室（≥3 个，其中 ≥2 个来自外部贡献者）
- **是什么**：不是"一个 AP 物理案例"，而是**几个能直接进去上课的成品教室**。每个都有：老师（1–3 位，有性格）、故事、课程表、知识点覆盖。
- **解决谁的时刻**：C 类（老师/家长）——**他们要的是成品，不是生成器**。
- **现状差多远**：现在只有 `AP_Physics_EM` 一个，且被定位成"演示案例"。
- **🔴 这是"接受 PR"落到实处的地方**：**外部已经有两个成品躺在 fork 里了**——
  - `94series`：`Advanced_Math`（**膜材料数学**），172 个文件纯新增、零删除 → **可干净合并**
  - `shentianming1994`：`DL_FromScratch`（深度学习，三老师：瑠夏/千鶴/墨）→ 会删掉上游演示，**不能整体合，但内容可抽取**
  → **"≥3 个教室里有 2 个是别人做的"这件事本身，就是招生官能读懂的那句采用事实。**

### F3 · 它记得你（🔴 护城河）
- **是什么**：跨会话的记忆是**可见、可展示**的——"第 3 课你错了这个，第 11 课它自己回来问你"。错题本、复习队列、课堂日志、四人群聊，**这些机制你已经有了**（15+ 个 runtime 文件），但**对外完全不可见**。
- **解决谁的时刻**：D 类（技术圈）判断"巧不巧"的那一刻，以及所有人在**用了一周之后**回来说"这个真的不一样"。
- **现状差多远**：机制存在，**但没有被当成卖点呈现**——README 里它是一段说明文字，不是一个能看见的演示。
- **为什么这是护城河**：**苏格拉底式提问谁都能抄**（`socratic-method` 下已有 458★ / 269★ 的项目）；**"它记得你"抄不走**——它需要一整套状态管理设计，而且效果要时间才显现。**1,000★ 的项目必须有一个"只有它能做"的点，这就是那个点。**

### F4 · 看得见
- **是什么**：三样东西——① 一个**能点的 Live Demo**（不用装任何东西，打开就看到一节真实课堂）；② **README 首页一段真实课堂录屏**；③ **一段完整的真实课堂记录**（从"我不会这道题"到"我自己推出来了"）。
- **解决谁的时刻**：A 类（好奇的过路人）——**这是转化率，是乘数不是加法**。
- **现状差多远**：🔴【实测】**README 里 0 张图片**（只有 HTML badge）；没有在线站点。一个"沉浸式轻小说教学"项目**首页没有一个画面**。
- **为什么排第一**：★ 是"看到 → 看懂 → 想试 → 试成了 → star"这条链的末端。**链条前端现在是断的**——所以现在每一份流量都在漏。

### F5 · 能被装进任何 agent
- **是什么**：一个 **skill / plugin 包**（Claude Code 优先，其次 Cursor / Copilot），能被一条命令装进别人的工作流。
- **解决谁的时刻**：D 类 + 生态分发——**这是被 `awesome-claude-code`（【实测】54,368★）这类 curated list 收录的前提**。
- **现状差多远**：现在只是"一个仓库"，不是一个可安装的包。
- **顺带解决**：`agent-skills`（24,538 仓库）／`claude-skills`（8,739）／`claude-code`（75,057）这些**真实生态入口**的 topic 才有依据可挂。

## §4 五个功能里，哪个是「因」，哪个是「果」

不是五个都同等重要。按**它作用在链条的哪一段**分：

| 功能 | 作用 | 性质 |
|---|---|---|
| **F1 一条命令** ＋ **F4 看得见** | 决定**流量来了会不会变成 ★** | 🔴 **乘数**——没有它，后面所有事都白做 |
| **F2 成品教室** ＋ **F5 能装进生态** | 决定**能不能被分发出去** | **入口** |
| **F3 它记得你** | 决定**会不会被记住、被讨论、被推荐** | 🔴 **病毒系数** |

**如果只能做一个**：做 F4（看得见）——因为它是**唯一一个"即使不涨星也不亏"**的动作，而且它是其他所有动作的乘数。
**如果只能有一个差异化**：做 F3（它记得你）——因为它是**唯一不可替代**的。
**如果目标是"招生官能读懂的那句话"**：做 F2（≥3 个教室，其中 2 个别人做的）。

## §5 明确不做（陷阱清单）

30 天里这些**看起来该有**，但会拖垮项目：

| 不做 | 理由 |
|---|---|
| ❌ Web 版 / App 版 | 30 天做不完；而且**不是它的差异点**（ChatTutor 已经是一个完整的 Web 应用了，你打不过它做 Web） |
| ❌ 语音 / 图像 / 多模态 | 与"叙事 + 记忆"这条护城河无关，是分散火力 |
| ❌ 社区 / 论坛 / 讨论区 | 冷启动死路——你现在连 issue 都没开过，先有 1 个真实的用户往来再说 |
| ❌ "支持所有 AI 平台"的全兼容 | 先把 **Claude Code 一个做到最好**；全兼容 = 全不精 |
| ❌ 账号系统 / 云同步 | 一上云就要运维、要隐私政策、要花钱，30 天内会拖垮 |
| ❌ 为涨星持续更新内容 | 10–11 月你的时间轴不允许（TMUA/UCAS/托福/主文书 + EA + 香港 + UC） |

## §7 需要你确认的（含一个战略分叉）

1. 🔴 **定位**：接受"**一个会记住你的 AI 老师**"这个定位吗？——也就是把"生成你自己的系统"从**入口**降级成**进阶功能**。这是本文所有推导的前提。
2. 🔴 **战略分叉**：**"接受 PR"意味着让出部分主导权。** 你要的是——
   - **(a) 你的项目**：你定方向，别人提交的东西你挑着收；
   - **(b) 一群人的项目**：开放教室目录，别人可以维护自己的教室、有自己的署名。
   → 两者的产出不同：**(b) 更容易涨星、也更容易产出"外部贡献者"这句招生官能读懂的话**；**(a) 更可控，但回到"你一个人扛"**。
   → 我倾向 **(b)**，但这是你的项目，你定。
3. **Live Demo 放哪**（GitHub Pages ／ 你自己的域名 ／ 其他）——F4 依赖它。
4. **F2 的教室你愿意收几个别人的**？收谁的？（`94series` 的膜材料数学 / `shentianming1994` 的 DL_FromScratch / 其他）
