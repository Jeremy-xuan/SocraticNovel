## 一、md → 网页 的字段映射

**单一数据源**：`开源线/SocraticNovel_功能总清单_2026-09-24.md`（SHA-256 `b35ec968789c…`）。
网页**不含任何手写内容**：标题、分组名、63 条条目、每个数字、总览四个方框、进度条、筛选药丸上的计数，全部由这份 md 现场数出来。没有 JSON 中间层，没有硬编码条目表。

| md 里的东西 | 网页上的字段 | 渲染成什么 |
|---|---|---|
| `## 〇、教室内容本身（…）` 等 9 个 `##` 分组标题 | **分组** | ① 顶部导航的一格；② 「分组」筛选药丸；③ 页面里的一块分组区块（区块序号原样沿用 md 的 〇/一/二…）；④ 区块抬头自动写「分组 〇 · 8 项」 |
| `#` 列（`1`、`15b`…） | **编号** | 卡片左上角等宽小字；同时是卡片 DOM id（`item-15b`），筛选/搜索/锚点都用它 |
| `功能` 列 | **名称** | 卡片标题（h4，19px） |
| `一句话` 列 | **说明** | 卡片正文（14px，22px 行高） |
| `谁来做` 列 | **复用 / 自研** | 药丸标签：`复用` 走淡紫色、`自研` 走中性色；`自研（护城河）` 这类括注原样保留在标签里；md 里的完整原值（如 `**复用**（Anki 用的那套算法）`）挂在 `title` 悬停提示上 |
| `状态` 列 —— **标记部分**（✅／🟡／🔨／⬜） | **状态** | 状态药丸：四色阶梯（✅ 蓝 `#a0c3ec`／🟡 浅琥珀 `#ffc285`／🔨 橙 `#ff7a17`／⬜ 灰 `#7d8187`）+ 等宽字形徽标（`v`／`~`／`!`／`·`）+ 中文档名（已经能跑／做了一半／正在做／还没开始） |
| `状态` 列 —— **标记后面的全部文字** | **状态备注** | 卡片底部的「状态备注」区（发丝线之上）。例：`✅ 今天做完（开场材料从 82 KB 降到 54 KB）` → 状态＝`已经能跑`，备注＝`今天做完（开场材料从 82 KB 降到 54 KB）` |
| md 里行内的 `**加粗**` | 同名 | `<strong>`：**只换字色（body → ink），不加粗**——层级不许靠加粗，是本项目踩过的坑 |
| md 里行内的 `` `反引号` `` | 同名 | `<code>`：等宽体 + 发丝线描边的小块 |
| md 里的 emoji（🔴⚠️📌⭐…） | 行内符号 | 一律换成**等宽徽标**（沿用 `报告构建/` 的做法），避免彩色 emoji 破坏单面近黑的排版 |
| md 末尾 §九「数一数」自查表 | **数据一致性提示** | **不作为条目**。用来和表格行对账，差异渲染成页面顶部那个橙色提示块（见 §四） |

**没进网页的**：§九 的散文（如「11–13 以外的其余项…」）、§十「三块真正的拦路石」三句话。理由见 §六第 1 条。

### 状态口径（照抄 md 文件头，未自创）

md 第 5 行原文：`状态口径（四个）：✅ 已经能跑 ｜ 🟡 做了一半 ｜ 🔨 正在做 ｜ ⬜ 还没开始`。网页四档名称与此**逐字一致**。

### 进度条怎么算

顶部是 **四色堆叠条**（每档宽度 ∝ 项数）＋ 四个方框（各档项数 + 占比）＋ 一行 `63 项功能，19 项已经能跑（30%）`。

### 构建脚本的解析口径（健壮性）

- 分组标题：`## …`；表格：`|` 开头且下一行是 `|---|---|` 分隔行。
- 认表：表头含 `功能` + `状态` + `#` → **功能表**；表头含 `项数` + `状态` 但无 `功能` → **§九 自查表**；其余 → 记下来但不作为条目来源（构建时会打印"跳过的非功能表"）。
- 关键列 `#`／`功能`／`一句话`／`状态` 缺一即**报错并指出表头行号**。
- 每一行都校验：列数 == 表头列数、三列非空、编号不重复、状态列必须找到四个标记之一且**标记前不许有别的字**。任何一条不满足 → `ParseError`，**带行号**，构建以退出码 1 失败。**没有静默丢弃。**
- 未映射的 emoji：**警告**（带行号）但不阻断——正文照常渲染。
- 普通排版符号（`→`、`—`、`·`）**不会**被误判成 emoji。

### 5.2 为什么不加第 6 列「证据/备注」——以及替代方案

任务允许给 md 加第 6 列。**我判断这一轮不该加**，理由三条：

1. **填不出来就是编**。63 项里我手上**没有逐条可核的证据**。空着加一列 = 满屏占位符噪音；硬填 = 编造证据（违反学术诚信口径）。
2. **「备注」这一格其实已经有了**。md 的状态列本来就是 `标记 + 说明` 的写法（`✅ 今天做完（开场材料从 82 KB 降到 54 KB）`）。我把标记和后面的文字**拆成两个字段**渲染：状态 → 状态药丸，后面的文字 → 卡片底部的「状态备注」。**信息一条没丢，也不需要动 md。**
3. **加列是"以后要加证据链接时"的动作**，不是现在的动作。
