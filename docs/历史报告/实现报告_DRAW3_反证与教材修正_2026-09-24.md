## 5. ⑤ 修教材《第 3 讲》那句不成立的结论

### 5.1 核算（主代理的核算我复核过，逐项对齐）

三个任务都在 0 时刻到达，A 需 100、B/C 各需 10：

| 顺序 | 完成时刻 | **平均周转** | 首次运行时刻 | **平均响应** |
|---|---|---|---|---|
| A→B→C（FIFO） | 100 / 110 / 120 | (100+110+120)/3 = **110** | 0 / 100 / 110 | (0+100+110)/3 = **70** |
| B→C→A（短任务优先） | 10 / 20 / 120 | (10+20+120)/3 = **50** | 0 / 10 / 20 | (0+10+20)/3 = **10** |

⇒ **B→C→A 在两个指标上都更好**，原文那句「同一批任务，两个指标给出的"好顺序"不是同一个」**在这组数上不成立**。核算与主代理一致。

### 5.2 改动前后逐字对照（`materials/ch03.md`，第 30 行那一段的末句）

**改前（逐字）**：

> 想让它尽快做完，就该把 CPU 连着给同一个任务；想让它尽快被理睬，就该频繁换人。**任何只优化其中一个的调度器，都会在另一个上表现差**——这是本讲最值得让学生自己推出来的一条。用上面的例子检验：FIFO 的响应时间是 (0+100+110)/3 = 70，而 B→C→A 的顺序是 (0+10+20)/3 = 10。**同一批任务，两个指标给出的"好顺序"不是同一个。**

**改后（逐字）**：

> 想让它尽快做完，就该把 CPU 连着给同一个任务；想让它尽快被理睬，就该频繁换人。**任何只优化其中一个的调度器，都会在另一个上表现差**——这是本讲最值得让学生自己推出来的一条。不过要提醒一句：**上面那组数还看不出这个冲突。** 同样按那组数算响应时间，FIFO 是 (0+100+110)/3 = 70，B→C→A 是 (0+10+20)/3 = 10——和周转时间一样，**短任务优先在两个指标上都更好**，那组数证明的是"长任务堵住短任务"（KP-3.2），不是两个指标的冲突。**真正的冲突要等引入轮转（RR）才出现**：RR 让每个任务都很快被理睬，代价是谁都不能很快做完——见下面的「片段二 · 轮转」。所以这一步先让学生把两个指标分清楚、并自己说出"这组数还看不出冲突"，冲突留到片段二再兑现。

1. 🔴 **`classroom.yaml` 声明"AGENTS.md 交给宿主注入"，而宿主按**会话 cwd** 找它** ⇒ **cwd 不是教室目录时，`AGENTS.md` 的内容（含容错判据）根本不进上下文**。判据类实验必须先验"判据正文在不在上下文里"（本轮用"非 `tool/result` 的事件里有没有命中"来判，一次就抓出两次假结果）。
2. 🔴 **"指针命中 ≠ 正文在场"**：`session_log.md` 自己的文件头写着"判法见 `AGENTS.md` 的「课后更新容错」"——按字符串搜 `课后更新容错` 会**命中**，但那只是**指针**（在 `tool/result` 里）。⇒ 判"某条规则在不在上下文"，**必须排除 `tool/result`**（模型读到的文件内容不算系统指令）。
3. 🔴 **换数据源复核"好消息"**：我用 D2 组的**原始** `runs.jsonl` 做签名筛查，得到"有纪律 0 次"，那是**假阴性**（该文件 `assistantFull` 全空，正是 DRAW-2 已修的 bug）。⇒ 凡"某现象 0 次"的结论，先问"这个 0 会不会是数据源坏了"，并用**第二份数据源**（`runs.enriched.jsonl`）复核。
4. **驱动脚本自己也会坏**：`OUT` 目录不存在时 `appendFileSync` 抛 `ENOENT`，**会话已经跑完、记录却丢了**（本轮白烧 2 次会话）。⇒ 驱动脚本**先 `mkdirSync(OUT, {recursive:true})`**；并把"跑完立刻写盘"当作硬要求（本轮已如此，所以其余 25 条一条没丢）。
5. **`tool/call` 的入参键名不固定**：模型用 `bash tail -60 runtime/session_log.md` 代替 `read` 时，我的"文件路径清单"里什么都看不到——**统计"它读没读某个文件"要连 bash 命令一起扫**，否则会得出"它没读"的错误结论（本轮 FT1 差点被误判）。
6. **判定的过程在 `reasoning` 块里，不在 `text` 里**：只看正文会得出"它没判"的结论；`reasoning` 要从 session 文件重抽（`tmp/draw3/inspect-reasoning.mjs`）。
