## 1 · 工具形状与理由（J1 的落点选择）

新增课上工具 **`classroom_enter_lesson(lesson: N)`**，没有扩 `classroom_set_phase`。三条理由：

1. **写的是另一组键**。`classroom_set_phase` 的契约是「只写 `current_phase` 一行、不动别的」
   （契约 K3.3.4 第 4 条）。跳讲要写 `current_lesson` ＋ 新增的 `skipped_lessons` ＋ 人读表格的
   两行。合成一个工具，就把两条互不相干的写路径绑死：任一侧改判据（比如 A 车道将来改了
   `progress.md` 的人读行格式）都会牵动另一侧。
2. **返回值形态不同**。跳讲要一次交出几 KB 的机械摘录（前情提要 ＋ 前置知识点）；
   `set_phase` 的返回值是一句给模型/面板看的短状态。塞在一起的代价是 `set_phase` 每次换相位
   都背着一个用不上的大字段。
3. **触发词不同**（「从第 N 讲开始」 vs 「进入追问环节」）。本项目实证：条件措辞会让模型犹豫、
   工具就够不着（`实现报告_T3a` §4，`index.mjs` 的 `DRAW_TOOL_DESCRIPTION` 注释里也引了这条）。
   两条触发各写死在各自的工具描述里，模型不需要在两个语义之间自己判断该调哪一个。

工具描述（`ENTER_LESSON_TOOL_DESCRIPTION`，英文、动词优先）里把三件模型会猜错的事实写死了：
**跳过 ≠ 掌握**（不许说"你已经会了"）、**返回值里已经带着机械摘录**（不许自己编前情）、
**`persisted:false` 就是没切成功**（不许按新讲次继续讲）。第 ⑧ 条单测盯着这三句不被改掉。

## 2 · 写入契约（`progress.md`）

一次 `withFileLock` ＋ `writeFileAtomic`（宿主 `@deepseek-ai/dsh-atomic-write`，`mode 0600`），
**只动四处，其余逐字保留**（第 ③ 条单测按行比对）：

| 位置 | 变成 |
|---|---|
| 机器行 `current_lesson:` | `N`（找不到就**报错**，不凭空插一行造出第二个来源） |
| 机器行 `skipped_lessons:` | `1,2,3,4`（升序逗号分隔）；集合为空 → **整行删除**（契约：「缺失＝无跳过」，不留空值行） |
| 人读行 `\| 本轮要讲 \|` | `**第 N 讲 · <标题>**`（标题机械取自 `knowledge_points.md` 的 `## 第 N 讲 · …`；没有就不写标题，不编） |
| 人读行 `\| 跳过的讲次 \|` | `第 1–4 讲`（连续段折成区间，空集写 `—`）；**文件里没这一行就不造** |

人读行与机器行必须同值，这不是美观问题：面板（`clients/classroom-ui/lib/client.js:4853`）
两边不一致会直接提示「口径不一致」。

**先写盘、后改内存**：`enterLesson()` 失败时把 `lesson` **原样退回旧值**，`index.mjs` 只在
`persisted === true` 时赋给闭包变量 `currentLesson`。所以「内存说第 5 讲、盘上还是第 1 讲」
这种状态在两种接线方式下都构造不出来（第 ⑦⑨ 条单测：写盘失败 → `classroom_status` 仍报第 1 讲）。

## 3 · 注入集合规则（J1 的提要 ＋ J3 的门）

### 3.1 故事节点：不用新机制，靠既有的讲次门

`classroom.yaml` 里 `story.node.01..14` 都挂着 `lesson: {current: true, of: N}`，而讲次只由
`current_lesson` 驱动。跳讲改的正是这一行 → **注入哪些故事节点完全由这条门决定**，跳到第 N 讲之后
只有 `story.node.N` 放行。第 ⑤ 条单测把 1–14 全扫一遍（每讲只放行自己那一个），另有端到端一条：
跳讲返回值与下一回合的注入计划里都没有第 6 讲及以后的故事节点。

### 3.2 前情提要：只取 `< N`，且只取「连续性要点」那一段（逐条机械规则）

| 源 | 取什么 | 不取什么（为什么不取） |
|---|---|---|
| `story/ch01.md` | 「这一讲在故事里的作用」段的**正文** | 「留给后面的事」——那一段就是"以后才说"的清单 |
| `story/ch{02..N-1}.md` | 「本讲位置」段的**正文** | 「场景节点」「机会节点」「暗线种子」——里面写着**后面几讲**的回收点（如 ch02 的「（ch14 回收）」）；取它们＝提前剧透 |
| `story/overview.md` | 「人物弧」表里**讲次区间含 N** 的那一行，只取**前三格**（段 / 讲次 / 状态） | 第四格「标志」——它写的是"第 9 讲她主动讲起…""第 14 讲她第一次…"这类**后面几讲的里程碑**；「暗线种子总表」「物件出现表」同理 |
| `story/overview.md` | 「每讲核心疑问」表里 **`< N`** 的行 | `≥ N` 的行（第 N 讲自己的疑问由 `curriculum` 的注入块给，不重复）；**「情感线备注」列不取**（那是写作备忘，且写着后面几讲的回收） |
| `knowledge_points.md` | 第 `1..N-1` 讲的**知识点行原文**（`- [ ] **KP-…** —— 判据：…`） | 第 N 讲自己的条目（它属于"本讲要拿下的"，不是"前置"）；段内的格式说明文字 |

第 ④ 条单测的反例断言是**逐字比对**而不是"大概没提"：拿 ch05/ch06/ch09/ch14 里一条正文行去
`recap.includes(...)`，必须为 `false`；并把「人物弧前三格」的 JSON 拿去断言不含 `第 9 讲` / `被覆盖`。

没摘到的文件或段（story 缺文件、overview 缺人物弧行、知识点缺条目）**如实列进** recap 末尾的
「没摘到的部分」，不假装完整（第 ④ 条与第 ⑦ 条各有一条断言）。

### 3.3 「前置知识点」的取法与两档体量

文档说「加上第 N 讲的前置知识点」。跳到第 N 讲的学生，缺的正是前面几讲本该拿下的东西；
第 N 讲自己的知识点由 `curriculum`／本讲清单在开场注入（既有机制）。所以：

- **前置** = 第 1..N-1 讲的知识点；第 N 讲自己的条目**不进**这一块，但用它当 recap 的标题；
- **分两档**（`PREREQ_FULL_WINDOW = 2`，2026-10-21 主代理拍板）：**近两讲（N-2、N-1）给条目原文**
  （含判据），**更早的只列标题** `· KP-x.y 标题`，一行一条。理由：跳到第 14 讲时全量原文这一块
  约 **7.6 KB**，会挤掉别的注入块，而「学生真正需要的前置」几乎都在近两讲；判据他自己去读
  `knowledge_points.md` 那一节即可。
- 实测（第 14 讲）：这一块 **7651 B → 3339 B**（不到一半），8 条原文行 ＋ 46 条标题行。
  改窗口只改这一个常量。

## 5 · EC 逐条怎么处理的

| EC | 处理 | 断言 |
|---|---|---|
| **N 越界：0** | `parseLessonNumber` 报错并说明「第 0 讲＝还没开始，不是讲次」 | ① |
| **N 越界：15** | 按 `classroom.yaml` 的 `classroom.lessons: 14` 拒，报错带 `1–14` | ①（另有「教室没声明上界 → 只校验 ≥1，不猜上界」一条对照） |
| **N 非数字** | 工具参数 schema 是 `integer`（宿主先拦一层）；`parseLessonNumber` 再对 `"abc"/""/null/{}/true/5.5/NaN` 全部报错 | ① |
| **跳回已经上过的讲次** | 允许；后退**不新记**跳过，且把 `≥ N` 的旧跳过项剔掉（它们现在都在前面、要按顺序上） | ② 与 ⑦ 各一条（第 5 讲 → 第 3 讲，`skipped_lessons` 收敛成 `1,2`） |
| **跳讲之后又要求从头开始** | 允许（N=1）；`skipped_lessons` 整行**删除**，人读行回到 `—` | ② 与 ⑦ 各一条（第 5 讲 → 第 1 讲） |
| （补充）重复跳到同一讲 | 幂等：第二次写出的内容与第一次逐字节相同 | ⑦ |
| （补充）没有讲次门的教室 | 工具层直接拒绝（`currentLesson === null`），不猜、不假成功 | ⑦ |
| （补充）写盘失败 | `persisted:false` ＋ 原因；内存与盘都不动 | ⑦（io 注入）＋ ⑨（真只读目录） |

跳过集合的口径写在一处（`nextSkippedLessons`），规则三条：**只保留 `< N` 的旧值**；
**前进时把 `[previous, N)` 记成跳过**（含当时正在上的那一讲——`current_lesson` 的语义是
「本轮要讲的讲次」，讲到一半走了＝这讲没上完）；**后退不新记**。
