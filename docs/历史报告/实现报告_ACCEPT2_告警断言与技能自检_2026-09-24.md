## 1. 新断言编号 / 位置 / 白名单逐条理由

- **编号**：`A6.5`。A1–A6 的编号与语义**一个都没动**，新增只是 A6 内部的一个小项。

**为什么挂 A6 之下而不是新开 A7**（源码注释逐字在 `asserts.mjs:482–486`）：
1. A6 的主题是"有没有东西被**静默吞掉／静默漏掉**"，而"宿主告警看得见了但没人管"是同一主题的另一种形态；

### 1.2 断言语义（逐字）

> 日志桥收到的 `error`/`warn` 里，**出现一条不在白名单内的条目 → 整条 A6 判失败**。

失败时的报错文本（`asserts.mjs:592–601`）会把**每一条**非白名单条目的级别、模块名、前 200 字符 args 打出来，
并附上纪律提示："若确认它不归我们，请按 `lib/whitelist.mjs` 的纪律（写明理由＋指向取证件）加白；不许'看不懂就加白'"。

**另外三条不静默的护栏**（同样属 A6.5）：
- 日志桥探针无产出 / exporter 未注册 → **判失败**（不当作"没有告警"）；
- 桥已注册、正向对照已到达，但日志文件里**一条消息都没有** → **判失败**（`asserts.mjs:586–591`，明确写"这个结论不成立"）；
- `info`/`debug` **不计入**"宿主告警"（只判 `error`/`warn`，`whitelist.mjs:140–142`）。

### 3.3 本轮修的两个真实缺陷（都在第 ⑤ 项里）

**缺陷 A — 没有 `--project-root`，建议路径是废话。**
原实现从"本包的父目录"向上找 `.git` 定项目根。本仓库**没有 `.git`**（已实测：工作区根、`开源线/DSH定制/`、
`code/`、`code/skills/` 四处都没有）→ 回落成父目录 `code/skills/`，于是打印的建议路径变成
`code/skills/.dsh/skills/socratic-classroom`——**听着像答案、其实没人会照做**。
→ 修法：加 `--project-root <目录>` 覆盖；并在**回落发生时明说**这是推断值、以及怎么校准（见 §3.4 跑①）。

**缺陷 B — `/tmp` 软链接导致假红。**
macOS 上 `/tmp` 是指向 `/private/tmp` 的软链接。`__dirname` 拿到的是**已解析**的 `/private/tmp/…`，
而命令行传进来的 `--project-root /tmp/…` 是**未解析**的 → 两者 `path.resolve` 后仍不等，
"本包明明就在 `<项目根>/.dsh/skills/` 下"却被判成"不在任何扫描根下"。
→ 修法：新增 `canonicalize()`（`path.resolve` ＋ 能成功就 `realpath`），**判路径相等一律两边都归一**。
（这个 bug 是跑第②跑时**当场暴露**的：第一次跑②报"不在"，修完才报"在"。）
