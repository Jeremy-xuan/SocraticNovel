## §1 AnimaTutor 到底做了什么（实测解剖）

### 1.1 三个自造概念（【AT】README）

| 概念 | 它的定义（README 逐字） |
|---|---|
| **Ur-Prompt · 原始叙事提示词** | "一切生成系统的叙事源头"。"**不是一个功能性的 prompt，不是一份规则清单，不是一个角色描述表。它是一个完整的、经过创作验证的叙事系统**" |
| **Multi-Prompt Design · 多文件协议设计** | "**把最重要的信息始终保持在上下文的最近位置**"。理由逐字：*"单体 prompt 超过 4000 字后，AI 的注意力在上下文中被稀释，**角色开始漂移，规则开始失效，故事开始走形**"*。→ 8 个职责不交叉的文件，"**每轮刷新，每轮锚定，让 AI 在第 50 轮对话里和第 1 轮一样清楚自己是谁**" |

### 1.2 它已经解决了"陪伴为什么成立"这个理论问题

## §3 五条设计机制（把中间那一档填上）

### 机制一 · 记忆是累积的，不是承诺换来的
**关键洞察**：陪伴不需要"先承诺一学期"，它需要"**每次交互都留下痕迹**"。
- 第 1 次来问一道题 → 系统建一个**最小档案**（你的卡点、你的表达习惯）
- 第 2 次来 → **它说"上次你卡在三角换元"** ← 🔴 **陪伴的第一个瞬间，发生在第 2 次交互，不是第 20 次**
- 【原文】的对照：原文作者是上到**第 7 节课**才"感动到想哭"。→ **碎片化版本必须把"感受到陪伴"所需的交互次数从第 7 次压到第 2 次。**
- 实现素材：`06_状态追踪模板.md` + `07_角色记忆.md`，但需要一个**最小版**（单文件，不依赖 8 文件架构）

### 机制二 · "一道题 = 章节触发器" 降级为 "一道题 = 一个场景片段"
- **α 版**：一道题触发一个**章节**（推进主线）
- **碎片版**：一道题触发一个**日常场景片段**——有角色、有氛围、有她的反应，但**不推进主线**
- 累积到一定次数 → **系统提议升级**（见 §4）
- 依据：【AT】"你的每一道题是**章节触发器**，但章节本身是完整的文学叙事"——**这个机制可以降级复用**

### 机制三 · 🔴 连接理由在碎片化场景下反而更强（这是"会不会变成其他项目"的答案）
【AT】原话：**"连接理由是刚性的。你有题不会，你必须来。这是一个客观存在的需求，不依赖情绪，不依赖好感，不依赖你'扮演'一个喜欢她的人。"**

→ 🔴 **"我真的不会"是最硬的连接理由。碎片化用户每一次来访都是真实的**（他不是来"演"的、不是来"谈恋爱"的）。
→ **所以：碎片化不是陪伴的敌人，碎片化恰恰是连接理由最强的时候。**
→ 🔴 **真正会破坏陪伴的，是让用户"为了叙事而叙事"。** 那一刻它就变成普通 gal game，而**沉浸单独已被验证没人要（`topic:visual-novel topic:education` 全站最高 1★）**。
→ **判据**：**如果一道题不存在，这次交互还成立吗？** 成立 → 已经跑偏了。

### 机制四 · 展示"累积物"，不展示"进度"
- **进度**（"第 7 课 / 共 30 课"）→ 需要线性承诺才有意义
- **累积物**（你的卡点清单、她对你提问习惯的记忆、你上次问过的问题被引用、你搞懂过的概念列表）→ 🔴 **不需要线性承诺**
- 🔴 **这回收了 Q1 的定案**：**"基于文字的系统"正好适合展示累积物**——数值化的好感度反而需要线性承诺才能显得有意义。**你的 Q1 答案和这个设计是自洽的。**

### 机制五 · 用"非线性情感里程碑"做碎片化入口
【AT】`04_故事线锚点.md` 的定位就是"**非线性**情感里程碑"→ 碎片化用户可以从**任意里程碑**进入，不必从第一章开始。**这是 AnimaTutor 已经写在架构里的取向。**

## §4 🔴 关键设计：碎片化 → 结构化的升级阶梯

**这是整套设计里唯一的新东西**（AnimaTutor 里没有）。

单题需求天然会暴露知识缺口，**而知识缺口天然指向一条学习路径**。所以：

```
搞懂一道题  →  它识别出你缺的是「三角换元」
            →  提议一条最小路径（3 节课，不是 30 节）
            →  你上完 → 它说"这条线你通了，要不要看看它接去哪"
            →  一门课（教室）
```

**每一级都是可退出、可停留的**：
- 停在第一级 → 你得到的是一个"**记得你的答疑老师**"（比普通 AI 助手强，因为它记得）
- 走到第四级 → 你得到的是一个**长期陪伴的学习系统**

🔴 **关键**：**教室不是碎片化的替代品，是碎片化的延伸。** 这同时回收了上一稿的**轴 1（教室库）与轴 2（单节课）之争——它们不是二选一，是同一条阶梯的两端。**
→ 所以**先做轴 2**（阶梯入口，更小、直接产出传播单元），轴 1 随后（阶梯顶端，社区贡献的载体）。
