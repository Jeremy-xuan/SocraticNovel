### 2.4 一次安装事故（已查明，非依赖问题）

第一次 `pip install` **全部失败**：`SSLError(SSLCertVerificationError … unable to get local issuer certificate)`。
**根因**：本机 `/Library/Frameworks/Python.framework/Versions/3.13/etc/openssl/` **目录是空的**（没有 `cert.pem`），

**修法**：`SSL_CERT_FILE=/etc/ssl/cert.pem`。🔴 **没有换镜像源**（诊断清楚才动手，不空转）。

### 4.5 🔴 更重要的发现：中文在**真实教学脚本**里的问题不是"能不能渲染"，而是"有多宽"

| 中文相关问题 | 出现次数（/12） |
|---|---|
| 缺字 / 豆腐块 | **0** |
| 中文没显示 | **0** |
| **字宽估算失准导致标签重叠/被压住** | **3**（A_P1、A_P4、C_P3） |
| 对比度不足（浅色字配浅色底） | **1**（B_P1） |

→ 【推断】中文的风险点不在字形支持，而在**字宽/行高需要实测**（Pango 量一次 `Text(...).width` 即可），
   而**模型在没有渲染反馈时不会去量** —— 子代理自述里自己承认了这一点（B_P3：「若 PingFang SC 实际渲染更宽，

   **没有一例把机制讲反**；**全部是"改文案或调坐标"级别**的修复，**没有一例需要重写脚本**。
3. **F3（版本变更）与 F1（幻觉 API）在 12 例里都是 0 次** → 横评最担心的那个风险在本路由 n=12 里**没有复现**。

**不能说明的（写死，防过度解读）**：
- ❌ **不能说"RITL 有效/无效"** —— 基线打满（12/12），**循环一次都没触发**，本实验对这个问题**零信息量**。
- ❌ **不能说"文档注入提升了可用性"** —— A 与 C 都是 3/4，无差异。
- ❌ **不能说"RITL 让可用性变差"**（B 组 1/4）—— n=4，且 B 组的低分集中在标签遮挡这类**偶发排版问题**。
- ❌ **不能把 58.3% 当作"模型的教学动画可用率"** —— 点位是本项目自挑的 4 个、单一路由、n=12。

## 7. 🔴 本实验的适用边界（**写死**）

1. **只对本机这一条路由成立**：`work-buddy` / `deepseek-v4.1-flash` / `reasoning_effort=high`。
   换模型、换供应商、换 effort → **本报告全部数字作废，须重测**。
2. **只对 `manim==0.21.0` + Python 3.13.2 + macOS 15.7.5 arm64 这一组成立**。
   换 ManimCE 版本 = 重新验证（横评 §7.1 的"版本锚定"要求，本 PoC 已执行）。
3. **n 极小**（4 点位 × 3 组 = 12 次渲染）。**只能读作"本路由下 n=12 的实测"，不许当普遍规律。**
4. 🔴 **本次实验的任务书本身降低了难度，必须说清**：
   三组的提示词都显式给了「**本机没装 LaTeX，绝不用 `Tex`/`MathTex`**」与「中文用 `font="PingFang SC"`」。
   → 这两条**恰好挡掉了公开论文里最常见的两类失败**。**换成不给这些提示的真实教室场景，成功率可能下降。**
   → 【推断】这也是为什么 F1/F3/F6 三类失败都是 0。
5. **渲染成功率 ≠ 教学可用性**（第 6 节已单独判）。
6. **拿不准的一律标【待核】，不编**（见第 9 节）。

## 🔴 勘误（2026-09-24，由 ANIM-GATE 逐像素复核后、主代理落盘）

**本报告第 276／290 行那处结论——「B_P2 的『到点！硬件打断』与『内核决定』之间**没有箭头**（因果链没画）」——经复核不成立，现予更正：**

- ANIM-GATE 实测 `r1_B_P2` 画面里**红色线状结构 3119 px、紫色 3193 px** → **箭头在画面里**。
- 更直接的旁证：**本报告在同一行的描述里就写着"绿色箭头方向可读，只是因果链多绕一步"** → 那句说的是**语义**（因果链多绕一步），**不是"没有箭头"**。
- **结论更正**：B_P2 的缺陷性质**从"缺箭头（画面层）"改为"因果链多绕一步（语义层）"**；§6 里"5 例缺陷全部是画面层"这句话随之更正为**"4 例画面层 ＋ 1 例语义层"**。
- 🔴 **另补记一处本报告漏掉的真缺陷**（ANIM-GATE 发现）：**`r1_B_P2` 末帧的白色结论句压在白色标题上**（同色文字重叠）——质量闸门目前对它**只给 warn**，是本次唯一的真漏报。**这处是学生真的会看到的**，已列入闸门"必须人看"的清单。
