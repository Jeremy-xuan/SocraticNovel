## §0 先把纠正后的架构写清

**引擎 × 内容分离**（用户纠正后的定形，可推翻）：

```
┌─ 插件侧（宿主确定性机制，改一次、全体教室受益）─────────┐
│  教室加载器/注入引擎：读教室 manifest（每文件标 position+frequency） │
│  → 按规则逐个确定性注入（pre-step / system section / turn-stopping）  │
└──────────────────────────────────────────────────┘
┌─ 数据侧（可分享、可混搭、零代码）────────────────────┐
│  教室包 = 人格 + 叙事规则 + 纪律 + 教材 + 故事线 + 课程表 + 知识点       │
│  每个板块带注入元数据（酒馆式 position/depth/frequency 的我们版）      │
└──────────────────────────────────────────────────┘
```

对照酒馆：这就是把 `populationInjectionPrompts`（拼装层）做成插件，把 character_book / 世界书条目做成数据——**酒馆的架构分工，原样平移**。
