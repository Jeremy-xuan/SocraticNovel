### A（K3）细节

- **真源**：`<教室>/runtime/notes.jsonl`，一行一条；字段严格照 K3.2（`v/id/ts/session/lesson/turn/type/kp/quote/note/origin`），`resolved` **不写**（只在投影时推导）。
- **id**：`N-<yyyyMMddTHHmmss>-<三位序号>`，同秒内靠序号区分（`nextSeqFor` 在**锁内**重读后取号）。
- **三份投影**（`mistake_log.md` / `review_queue.md` / `knowledge_points.md` 状态位）：整文件重写，文件头逐字
  `> 本文件由 runtime/notes.jsonl 机械生成，请勿手改。`
- **推导规则**（K3.3；README「课堂记录」段有人读版，`test/notestore.test.mjs` 每条一条单测）：
  1. 状态位取该 kp **时间序最后一条**学习类记录：`evidence`→`[x]`、`misconception`/`blocker`→`[~]`、无记录→**不动**；
     kp 所属讲次被跳过（`progress.md` 的 `skipped_lessons:` 行）→ 状态位不动、行尾加「（跳过）」（J2 红线）。
  2. 错题本：每条 `misconception|blocker` 一行；`resolved` = 同 kp 上存在**更晚**的 `evidence`；已解决的保留并标「已解决（第 N 讲 · 第 T 回合）」。
  3. 复习队列：到期点 = 记录讲次 **+1/+3/+7**（≤ 总讲数；`lesson=0` 不排期）；同一 kp 只按**最早一条**排期；`resolved` 后到期点作废（计划仍列出）；到期点显示**最近一个已过去的**（"现在欠哪一次"）。
  4. `progress.md`：**只读不写**（写它是模型课后更新的职责，课中工具若也写会抢同一文件）。`totalLessons` 取自 `knowledge_points.md` 的最大讲次号。
- **幂等**：同回合（`session`+`turn`）且 `type`+`kp`+清洗后 `quote` 全同 → 返回既有记录、不追加。身份用 postclass `turnMarker` 编码的同一对字段，**不新造键**。
- **并发**：`withFileLock` + `writeFileAtomic`（0600），锁内重读再判重；投影在真源落盘后重算，失败会明说「记录已落盘、投影未更新」。
- **EC 全覆盖**：kp 不存在 → 报错并给现有编号示例；`quote` 空/全空白/只有标记/只有 `**` → 报错；均**不落盘**（测试断言 JSONL 与三份投影一个字都没写）。

## 三 · 契约不够用 / 需要主代理决定的事

1. 🔴 **K1.2 只剥 `text-delta` 不够**（请追认，我按"目的优先"实现了扩展）。
   宿主 `dsh-llm` 的 `BlockAssembler` 在 `block-end` 处用 `chunk.block` **覆盖**它按 delta 累加的文本
   （`dsh-llm/lib/index.js:992`），而适配器给的 `block.text` 是**未剥原文**。
   只剥 delta 的实测后果：`emotions.jsonl` 有事件，但 headless 打印的正文、落盘的 `assistant/message` **仍带标记**。
   → 现在的实现：额外对 `block-end` 里**文本块**的 `block.text` 做同一份剥离（`reasoning` 块不动）。
   建议契约 K1.2 第 2 条改成「改 `text-delta.text` 与 `block-end.block.text`（仅文本块），其余原样透传」。
2. **K1.3 的"什么才算标记"**：契约写"非法标签/强度越界/缺两位小数 → 整个标记剥掉"。我原先实现成"凡是成对的 `〔…〕` 都剥"，
   与舞台版不一致（舞台版只处理 `emo:` 开头的）。已按舞台版收窄并在契约文字上理解为"非法**标记**"。
   建议契约补一句：**只有以 `emo:` 开头的括号对是标记候选，其它 `〔…〕` 属正文**。
3. **K3.3-1 的"跳过讲次"没有取值来源**：契约说"该 kp 所属讲次在 `progress.md` 里是「跳过」"，但 J（任意讲次进入）还没实现，
   `progress.md` 里没有这个字段。我的实现读**可选**机器可读行 `skipped_lessons: 1,2,3`（缺失＝没有跳过），并写进了 README。
   → 建议 J 的实现统一用这个键名（或由主代理改契约指定别的名字），否则两边会各写一套。
4. **K3.4 的块 id 与"区分"**：我按建议用了 `state.mistakes.due` / `state.review.due`，但为了"区分"不得不收窄既有两块（见 §一）。
