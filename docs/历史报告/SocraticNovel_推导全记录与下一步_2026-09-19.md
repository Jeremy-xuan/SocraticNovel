## 一、一句话：这个项目现在是什么

**一个"会记住你的 AI 老师"，但真正不可替代的是它给你写教材。**

- 别的 AI 家教（Bloom 269★、ChatTutor 1316★）教你"任何东西"，**教材是别人的**
- 主打沉浸的项目全站几乎没人（`视觉小说 × 教育` 只有 9 个仓库、最高 1★）
- **我们的位置 = 专属教材 × 沉浸叙事**：教材是为这个人写的，老师是故事里的人

**核心判断**：主打学习系统的没有我们的沉浸，主打沉浸的没有我们的学习系统——**两者的结合才是这个项目**。

## 二、推导过程（八步）

### 1. 起点：它算不算开源线的另一条支线？
**不算，是同一大类下的第二条腿。** 开源线主线（给别人提 PR）证明的是**外部认可**；自己的仓库证明的是**自主创造**。而它现在缺的恰恰是外部认可那一半——**全历史 0 个 issue、0 个 PR、贡献者只有我一个人**，而且停更半年。

**为什么五个月没人来**：门在邀请但没装把手。README 首推 Claude Code，可根目录没有 `CLAUDE.md`——**fork 我的人第一件事就是自己补这个文件**。

### 2. 目标：30 天 1,000★
- 同赛道有真实先例：`human-skill-tree` **557★ / 18 天 ≈ 31★/天**（正好是 1000★/30天 需要的速率）
- 但 **1,000★/30 天在本赛道没有先例**（最高 557）→ **必须叠加至少 3 个独立事件，单点爆款不够**
- **硬前提**：仓库 `language = null`，一行代码都没有。加代码不是加分项，**是 1,000★ 的必要条件**

### 3. 赛道地图：该打哪几个第一
| topic | 第 1 名 | 说明 |
|---|---|---|
| `immersive-learning` | **我 31★** | ❌ **虚的，不能用**——全 topic 只有 5 个仓库，第 2 名才 3★，点进去就露 |
| `narrative-ai` | 189★ | ✅ **要打**（需 >189★） |
| `socratic-method` | 458★ | ✅ **要打**（需 >458★） |
| `ai-education` | 1,316★ | ✅ 前三（需 >788★）→ **1,000★ 正好一起拿下** |

关键认识：**"这个方向上被使用最多的开源项目"这句话，200★ 就能拿到**。★ 在全局一点都不稀有（全站 ≥1,000★ 的仓库有 6.5 万个），**"我在哪个方向第几"才是卖点，"我有多少★"不是**。

### 4. 竞品：坏消息与好消息
- 🔴 **坏消息**：`Li-Evan/Bloom` 269★ **就是我想做的终极形态**——"Claude Code skill + 自托管 web app"双形态、MIT、18 个 topic、**还在更新**（2026-09-17）、定位"中文优先 苏格拉底式 AI 家教"
- ✅ **好消息**：那篇知乎原文的公开复现者全站只有 2 个（除我之外），**而且都停更了**。需求被验证（原文 502 赞同 / 98 评论），**供给几乎为零，没有赢家**

### 5. 读原文：三个改变判断的事实
1. **方法已经公开，作者主动放弃独占**（原话"以一种开源精神来拥抱竞争与合作吧"）→ 不能靠"我知道这个方法"建立优势
2. **作者刻意排除了 gal game 方向**（"我并不想往恋爱养成的方向去发展"、情感**不做数值化**）→ **我要走的这个方向，是被原方案让出来的**
3. 🔴 **最贵的一步被所有复现者跳过了**：作者生成专属教材花了 **4 小时 + $350 API**（1000+ 页 / 90 课）；而另一位复现者直接用现成教材，然后卡在 **marker-pdf 把内存打爆**

### 6. 护城河：不是"完整"，是"专属教材"
- gal game 方向 ✅ 空（而且是被刻意让出的空）
- 专属教材 ✅ **更空**（全球搜不到像样项目，全是 0–2★）
- ❌ **"完整"不是护城河**——Bloom 已经很完整了

| 层 | 是什么 |
|---|---|
| 🔴 **护城河** | **专属教材生成**（把 $350／4 小时打到接近零） |
| **放大器** | **沉浸式叙事**（本身易模仿，但和专属教材结合后不可分） |
| **不可复制** | **真实运行过的记录**（别人能抄机制，抄不了"真的教完了一个学期"） |
| **不是护城河** | "完整"、"记得你"、"苏格拉底式提问"（都是原文公开内容，已有竞品） |

### 7. 人群：我原来把两件事混成一件了
| | **受众** | **用户** |
|---|---|---|
| 是谁 | 觉得有意思的人 | 真的用它学习的人 |
| 门槛 | 应该**极低** | 天然很高 |
| 决定 | **★ 数** | 留存与价值 |
| 规模 | **大得多** | 小 |

**"人群窄"是「用户」的属性，不是「受众」的属性。** 要涨★扩的是受众；要做价值服务的是用户。

**而且"窄"的根因不是人群小，是承诺门槛太高**：原文 502 赞同，公开复现者只有 2 个 → **"觉得好"的人远远多于"动手做"的人**。现在要动手得走 6 步（读长文 → 装工具 → 解决教材 → 生成 50 个文件 → 调试 → 才开始第一节课）。**每砍掉一步，人群自动变大一圈。**

**扩展优先级**：教室库（替用户解决教材）> 单节课模式（"今天想搞懂傅里叶变换"）> 终点导向（考 AP / 搞懂一个面试题）> **优先打"有截止日"的人**（考生、跨考、期中期末 ≫ 成人终身学习者）。

### 8. 碎片化 vs 长期陪伴：AnimaTutor 已经把答案做出来了
🔴 **AnimaTutor 才是我手里最成熟的那件东西**，SocraticNovel 的叙事层其实是它的降级版：

- 它自己造了三个概念：**Ur-Prompt**（一切生成系统的叙事源头，"不是一个功能性 prompt，是一个经过创作验证的叙事系统"）、**Multi-Prompt Design**（"单体 prompt 超 4000 字后注意力被稀释，角色开始漂移、规则开始失效"→ 8 个职责不交叉的文件，**每轮刷新锚定，让 AI 在第 50 轮和第 1 轮一样清楚自己是谁**）、**Pair Prompt**（同一世界、两套机制、一条情感弧线）
- 🔴 **它的 `03_学科场景机制.md` 就是那个"全项目最难的设计题"**——知识点 → 叙事隐喻映射，**六要素结构 × 五学科**（因果链 / 场景空间 / 映射规则 / 角色姿态 / **场景内推导机制** / 情感联动）。例：物理 = 感受者视角（"物理对她不是抽象公式，是她身上每一道伤的记忆"），场景内推导 = "**冰面上霜痕勾勒出公式，水面波纹排列成等式，坠落的雨滴暂停形成向量图**"
- 🔴 **它最值钱的是那段"陪伴为什么成立"的理论**：
  > "普通语C……两个人之间除了聊天，**没有任何共同完成过的、真实的、有重量的事情**发生过。**凭什么会有感情？**"
  > "这个系统里，**连接理由是刚性的。你有题不会，你必须来。这是一个客观存在的需求，不依赖情绪，不依赖好感，不依赖你'扮演'一个喜欢她的人。**"
  > **"感情不是聊出来的，是做出来的。"**

**它的缺口**：给了两个极端——单文件无限续航的**碎片版** vs 8 文件四阶段弧线的**长期版**，**中间那一档是空的**。而那一档就是我要做的产品。

## 三、产品设计：碎片化怎么不破坏陪伴

**核心认识：碎片化和长期陪伴不是两种模式，是同一个系统的"进入深度"。**

**五条机制：**

1. **记忆是累积的，不是承诺换来的。** 第一次来问一道题就建最小档案；**第二次来它说"上次你卡在三角换元"**——陪伴的第一个瞬间发生在第 2 次交互，不是第 20 次。（原文作者是上到第 7 节课才感动到想哭；碎片版必须把"感受到陪伴"的次数压到 2）
2. **"一道题 = 章节触发器"降级为"一道题 = 一个场景片段"**——有角色、有氛围、有她的反应，但不推进主线。
3. 🔴 **碎片化不是陪伴的敌人，恰恰是连接理由最强的时候**——"我真的不会"是最硬的理由。**真正会破坏陪伴的，是让用户"为了叙事而叙事"。**
   → **判据：如果这道题不存在，这次交互还成立吗？成立就是跑偏了。**
4. **展示"累积物"，不展示"进度"。** 进度（第 7 课/共 30 课）需要线性承诺；累积物（你的卡点清单、她对你提问习惯的记忆）不需要。
5. **用"非线性情感里程碑"做入口**——碎片化用户从任意里程碑进入，不必从第一章。

**升级阶梯（这套设计里唯一的新东西）：**
```
搞懂一道题 → 它识别出你缺「三角换元」 → 提议一条最小路径（3 节，不是 30 节）
→ 上完 → "这条线你通了，要不要看看它接去哪" → 一门课
```
每一级可退出可停留：**停在第一级 = 一个记得你的答疑老师；走到最后 = 长期陪伴的学习系统。**
→ **教室不是单节课的替代品，是它的延伸**（所以先做单节课，再做教室库）。

**三条红线：**
1. **沉浸是手段，学习是目的**（沉浸单独已被验证没人要：全站最高 1★）
2. **叙事不能污染教学正确性**（原文："最关键的不是三月七，而是苏格拉底"）
3. **任何"为了沉浸牺牲学习效果"的能力都是错方向**

**目标与执行**
15. 🔴 **30 天 1,000★**，同时拿下 `narrative-ai` 第 1、`socratic-method` 第 1、`ai-education` 前三
16. **两条线分开**：受众线（涨★）= 把一次课堂变成**可传播单元**；用户线（做价值）= 砍门槛
17. **不许买★／刷★／为排名建空 topic**（GitHub 会清，而且申请材料的链接任何人点开就能看，一条陡升曲线比 31★ 危险得多）
