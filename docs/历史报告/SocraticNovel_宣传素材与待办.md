## §0 三条已定案（宣传的宪法）

| # | 定案 | 出处 |
|---|---|---|
| 1 | 🔴 **类别声明 ≠ 传播素材，而且应该不一致** | A3 |
| 2 | 🔴 **受众 ≠ 用户**：★ 来自"觉得有意思的人"，价值来自"真用的人" | 人群与传播扩展 |
| 3 | 🔴 **★ 是输出，用户是实质，"用户带用户"才是降维打击** | E1 |

**展开**：

**① 类别声明选"成体系学习"，传播素材用"碎片答疑的片段"**
| | 选什么 | 为什么 |
|---|---|---|
| **类别声明**（对招生官/用户说"我们是什么"） | **成体系学习** | 差异化最强、最可叙述（"我做了一个能替代补习班的东西"） |
| **传播素材**（拿什么吸引人点进来） | **碎片答疑的片段** | 门槛低、有画面、能涨★ |

硬要统一，反而两头都弱。

**② 两条线分开**
- **受众线（涨★）**：把一次课堂变成**可传播单元**——让**不打算自学的人**也愿意看
- **用户线（做价值）**：砍门槛（教室库 > 单节课 > 终点导向 > 优先有截止日的人）

**③ 降维打击的精确化**
- ★ 需要**你去推**（渠道、媒体、Trending）→ 每次都要你动手
- **用户带用户不需要你动手** → 用户自己就是渠道，而且它是指数
- **燃料** = **一段可以分享的课堂对话**（F4 可分享片段）→ 🔴 **所以"可传播单元"同时服务涨★和 Referral**

## §2 对比素材（对外说"为什么换掉你现在用的"）

### 2.1 vs 四个成体系对手 —— 🔴 它们有一个**共同弱点**
| 对手 | 强项 | 🔴 弱点 |
|---|---|---|
| 机构 / 补习班 | 有老师、有节奏、有压力 | 贵；时间固定；**不可能为你一个人调教材** |
| 网课（录播） | 便宜、有画面、名师 | **被动**（听不懂不会停）；**不能提问**；进度它定 |
| 公开课（免费） | 免费、优质 | **不是为你设计的**（语言/难度/前置不匹配）；不能提问 |
| 生啃课本 | 免费、权威、可反复 | 枯燥；**卡住没人问**；"启动学习仍要克服畏难情绪"（【原文】） |

🔴 **共同弱点 = 都不能"为你一个人调整"**（一个老师对 N 个学生／一次录制对所有人／一个老师对全世界／一个作者对所有人）。
→ **我们的护城河（专属教材 + 一对一苏格拉底 + 记得你的卡点）正打在这个共同弱点上。**

### 2.2 vs GPT —— 四条弱点（用户 2026-09-19 补充）
| # | GPT 的弱点 | 我们的答案 |
|---|---|---|
| 1 | 🔴 **不讲人话——不会按你能够理解的方式讲清楚** | 根因是**它不知道你的理解水平在哪**，只能按"平均读者"讲。**我们记得你的卡点，所以能判断该从哪一层讲起**（= 诊断 B3 × 记忆 D 域） |
| 2 | 没有情感与场景——问完就走，没有关系 | C 域叙事 |
| 3 | 不记得你的**学习卡点**（它的 memory 是通用偏好记忆） | D 域 |
| 4 | 它的回答是**"展示"不是"引导"**（【原文】把"教"变成了"展示"，你是观众不是参与者） | B1 苏格拉底引擎 |

⚠️ **但优势很脆弱**：第 2 条容易被说成花架子，而且 GPT 一直在补 memory。
→ 🔴 **所以对 GPT 的定位不是"比它答得好"，是"比它更讲得懂你 + 更让你想再来一次"。**

### 2.3 vs Socratopia（【实测】2026-09-19）
| 项 | 值 |
|---|---|
| `bootition/Socratopia-Local` | **13★ / 3 forks** / TypeScript / created 2026-07-06 / pushed 2026-09-14 |
| 它的开源运营 | 🔴 **无 description、无 license、无 topics、无 homepage** |
| 全站搜 "Socratopia" | **只有 8 个仓库**，最高就是它 13★ |

🔴 **它活着但没占住开源位置** → **开源方案的位置是空的**。而且它创建（2026-07-06）**晚于 `SocraticNovel`（2026-03-22）**——我们是更早的那一个。

**可打的空档**：原作者公开的 7 条产品路线图里，**没有一条提到"死板课程/大学生"这个场景**，也**没提"把别人的教材翻译成你能懂的样子"**。

⚠️ **一处要小心的对比**：原作者路线图第 6 条是"**自己创造虚拟人形象与配音，以免 IP 纠纷**"，而我们选了"用 IP 角色做二创" → **这个对比别主动提，也别去踩**。

## §3 渠道清单 + 排期 + 验收线

### 3.1 四个杠杆（按"杠杆 ÷ 成本"排序）
**L1 · 转化率（最便宜，先做）**
- 🔴【实测】**当前 README 里 0 张图片**（只有 HTML badge），24KB 纯文字 → 一个"沉浸式轻小说教学"项目**首页没有一个画面**

- 补根目录 `CLAUDE.md`、修 README 快速开始（【实测】fork 的人第一件事就是自己补 CLAUDE.md → 入口是断的；**fork 是 GitHub 权重最重的信号之一**）

| 提交其他 curated list（awesome-llm-apps / awesome-education 等） | — |

**L3 · 一次性爆点（要"上榜"，不是"发一次"）**
- **HN Show HN** ／ **Reddit r/ClaudeAI、r/LocalLLaMA、r/ClaudeCode**（🔴 **分开发，不要同一天群发**）／ **Product Hunt** ／ X
- 🔴 **B 站是你独有、别人没有的渠道**（2 万粉）：一段"AI 老师真的在上课"的录屏 → B 站 → 挂 GitHub

**L4 · 制造"采用事实"（这才是给招生官看的那一半）**
- 收下 `94series` 的 3 个提交 → **仓库第一次外部合并**

- 目标产出：**"来自 N 个国家/地区的 M 位外部贡献者"** —— 这种句子招生官能读懂，★ 数不能
