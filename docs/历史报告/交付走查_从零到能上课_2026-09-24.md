## 3 · 装技能包（**最容易装错的一步**）

技能包是"不装插件也能上课"的轻量形态。**装法＝复制目录，没有 CLI**：

```bash
mkdir -p "<你的项目>/.dsh/skills"          # 只给一个项目用（推荐，优先级最高）
cp -R "开源线/DSH定制/code/skills/socratic-classroom" "<你的项目>/.dsh/skills/"
# 或：所有 profile 都能用（写用户级目录）
# cp -R "开源线/DSH定制/code/skills/socratic-classroom" "$DSH_HOME/skills/"
```

🔴 **验收信号（这一步不验收就等着踩坑）**
- ✅ **技能自检会直接回答"我在不在扫描根下"**（2026-09-24 已合入）：在正确位置→退出码 0 并报出「在 项目级 · `.dsh/skills` [rank=100]」；**在错误位置→退出码 1 并打印三条可复制的目标路径**（否则就是"候选 0、告警 0"的双重静默）；名字非法→退出码 1。
- 🔴 **放在 `code/skills/` 这种位置＝永远扫不到，而且是"候选 0、告警 0"的双重静默**——放错了不会有任何提示；
- 扫描根的判定规则：项目级根按"**最靠近的含 `.git` 的祖先目录**"，**没有 `.git` 就回落成当前目录**。

## 7 · 🔴 已知坑（都是真踩过的，照做能省几小时）

| # | 坑 | 怎么办 |
|---|---|---|
| 1 | **`plugin add` 对同版本依赖会说 `Already up to date` 而不刷新** | 先 `remove` 再 `add` |
| 2 | **profile 里的副本与源码是硬链接，但编辑会打断它** → 跑之前你以为在跑新代码，其实在跑旧代码 | **跑真实会话前显式同步＋逐文件核哈希**（验收流水线自己会做冻结与复核） |
| 3 | **插件绝不能把宿主核心包**（`@deepseek-ai/*`）装进自己的 `node_modules` | 会双实例、Symbol 失配、工具调用崩 |
| 4 | **cordis 的 `ctx.logger(name)` 只接受一个参数**；且**默认级别门会把 `warn` 也挡掉** → 用 `ctx.logger(name).info(...)` | 想让报错"一定被看见"就用 `info` |
| 5 | **技能加载失败是静默的**（只写日志、跳过） | 凡发包必自带自检；**放错位置＝双重静默** |
| 6 | **技能只扫两层**，嵌套的 `SKILL.md` 不会被发现 | 放成扫描根的**直接子项** |
| 7 | **常驻 worker 会吊住宿主进程**（曾挂到 600 s 被杀） | 命令超时**不等于**功能没成——先去目标目录看文件有没有落盘 |
| 8 | **消息区没有"说话人"字段** | 想显示"另一个人在说话"，最省的做法是**让该角色走注入通道并给一个独有的来源标记**（客户端会自动渲染成带名字的注入行） |
| 9 | 面板/立绘类插件的入口**不是** `rightbar` | 用 `sidebar.right.pane.tab` |
| 10 | **客户端插件的产物是惰性 CJS 表、宿主不转译** | 手写产物（`require("react")`＋`createElement`），**不需要打包器** |
