### 3. 🔴 成人内容过滤的开关在哪（你问的那个）

**位置**：Workshop 浏览页的**筛选面板**里，有一个下拉框，**名字就叫「Rating」**。
**它的选项**：`G` / `PG-12` / `R-15` / `R-18`。
**URL 参数写法**（我实测有效的那个）：

```
&excludedtags%5B0%5D=R-18        ← 排除 R-18（推荐，已用在上面所有链接里）
&requiredtags%5B0%5D=R-18        ← 反过来，只看 R-18
&requiredtags%5B0%5D=Live2D      ← 只要 Live2D 类型
```

⚠️ 两个实测细节：
- 参数要写**标签名**（`R-18`），**写数字 id（186144）不生效**。
- 选中筛选后页面上会出现一个小标签：**排除时图标是减号、包含时是加号**，文字都显示 `Rating: R-18` —— 靠图标和条数区分。

另外，**每个条目自己的页面上也标着 Rating**（页面底部一行 `Rating: G` 这种），所以你可以点进任何一条自己核。
