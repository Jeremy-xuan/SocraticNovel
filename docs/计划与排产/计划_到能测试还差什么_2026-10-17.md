### 🎯 网络那条已经查到底了（不是「VPN 坏了」）

`/etc/mihomo/config.yaml` 第 **240** 行：

```yaml
- DOMAIN-SUFFIX,dsharness.dpdns.org,DIRECT
```

班级自己的域名被**故意**指到直连（内部访问不该绕代理，这是对的）。
但 Antigravity 通道借的是这个域名的子域 `google.dsharness.dpdns.org`，于是它**也被指到了直连**——而这台服务器直连 Cloudflare 是不通的（直连 `www.cloudflare.com` = 000，经代理 = 200）。

→ **修法（精确、低风险、可回滚）**：在这条规则**之前**加一行

```yaml
- DOMAIN,google.dsharness.dpdns.org,<代理策略组名>
```

这样内部域名继续直连、班级行为不变，只有 Antigravity 子域改走代理。改完 `systemctl reload mihomo`（不重启，不掐断现有连接）。

→ 为什么不是直接改 stage 的 `NO_PROXY`：mihomo 是本地透明分流，DNS 与路由在它自己手里，实例侧的环境变量管不到它。

## 二 · 分四阶段，每段都有验收判据

### P0 · 让「一个人能上完一节课」（4 个工作项，估 4–6 小时）

| 步 | 做什么 | 验收判据 | 阻碍 |
|---|---|---|---|
| P0-1 | **定模型出口**（根因已找到，见下方） | 服务器上一条 curl 到 antigravity 返回 **200**；DSH 里发一句话拿到 assistant 文本 | 改动 mihomo（全班共享）**需你点头** |
| P0-2 | **装教学引擎** `socratic-engine` | `node check.mjs` 在服务器上通过；会话里出现引擎日志 `[socratic-engine]` | 它有 3 个 npm 依赖（jsdom／mermaid／yaml）**服务器装不了**（出网限制）→ 从本机 `npm install` 后整包上传，或配国内镜像 |
| P0-3 | **把教室包做成预设** `cs-os-classroom`：写 `preset.yml` ＋ `agent.cordis.yml`，把 49 文件教室与技能包放进去 | 新建会话时预设选择器里能选到「计算机系教室·操作系统」；选它后 system prompt 里带教室声明与 `_anchor` 纪律 | 无（纯文件） |
| P0-4 | **跑通一节真课**：建会话 → 选教室预设 → 发「我想学操作系统第一讲」→ 老师按相位讲课、能出选项/板书 | 会话里能看到：老师句子落纸带、选项卡片可点、点板书能出 L03 场景、连续 3 轮不崩 | 前一步全绿 |

**P0 完成后你能得到**：你自己（通过我的隧道或你自己连）能完整上一节课。
