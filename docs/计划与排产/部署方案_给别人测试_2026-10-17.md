## 一 · 为什么不能"装在某个学生实例上"

教室舞台是**客户端插件（bundle 层）**，不是教室内容（preset 层）：

| 层 | 装什么 | 影响面 |
|---|---|---|
| preset（`/opt/dsh-presets/…`） | 课程内容、提示词、技能 | 只影响**选择这个预设的会话**，逐会话生效 |
| plugin（`dsh.profile.bundles`） | 代码：舞台、面板、引擎 | **整个实例的界面**，进程级生效 |

而且有三条已实测的红线（`开源线/AGENTS.md`）：
① 皮肤/整屏插件一旦进 bundles，**它就成了启动链路的一部分**，包一坏整个 profile 起不来；
② 插件 render 抛错会被 `SlotErrorBoundary` **永久**变成崩溃占位；
③ 唯一的关闭出口不能放在 `shell.overlay`（我们用了 `Ctrl+Shift+M` 全局快捷键，符合这条）。

→ **结论：必须独立实例。挂在 u001–u020 / c001–c012 任何一个学生实例上，等于拿别人的界面做实验。**

## 二 · 三条路

### 路线 A · 独立测试实例（真上课场景的正解）

| 项 | 内容 |
|---|---|
| 做什么 | 新建实例 `stage01`（独立 systemd 单元 ＋ 独立端口 ＋ 独立 profile），bundles ＝ `dsh-base` ＋ `dsh-web-app` ＋ `classroom-stage-warm`；同时把教室包 `cs-os` 作为 preset 放进它的私有根 |
| 测试者得到什么 | 一个链接（＋必要时的口令），打开就是课堂界面，能真发消息、真收到老师回复 |
| 要碰的东西 | ① 建实例脚本（班级那套 `dsh-instance-create-*.sh` 会**同时注册网关与代理**）；② **gateway 一条路由**；③ 一个新端口 |
| 代价 | 中。需要你明确授权"在班级机器上新增一个实例并开对外入口"——上一轮你的原话是这些一律不许碰，所以这一步**必须你点头** |
| 回滚 | 停单元 ＋ 删 profile ＋ 撤 gateway 那条路由。纯增量，不涉及任何现有实例的配置 |
| 风险 | 低但不可忽略：新建实例的 profile 若写错，只影响它自己（与现有 33 个实例不共享 profile） |

### 路线 B · 在已有测试实例上"补丁叠加"

`dsh web --patch <overlay>` 把舞台作为**一次性补丁**挂进某个已存在的实例，**不改 bundles**。

- 适合：那台实例本来就是测试用、且有人盯着；
- 缺点：进程一重启就没了，测完必须手动卸；而且它会把界面临时改成舞台，**那台机器的其他人此刻不能用**。
- 我的判断：**不推荐给别人用**——它本质是"独占该实例"，和路线 A 的成本差不了多少，但可追溯性差。

### 路线 C · 静态演示页（先定观感，零风险）

| 项 | 内容 |
|---|---|
| 做什么 | 把舞台的**静态夹具页**（含背景、立绘、纸带、六态卡片、花饰、板书屏、动画屏）做成一个自包含 HTML，放链接给别人看 |
| 能测什么 | **观感**：像不像 galgame、纸带读起来累不累、选项认不认得出来、字号合不合适 |
| 测不了什么 | 交互链路（点了不会真发消息给模型）、真实延迟、多轮对话 |
| 代价 | 低。今天已经做出雏形：`code/clients/classroom-stage-warm/ornaments/fixture.html` ＋ `fixture-v5.png` |
| 风险 | 零。不碰服务器、不碰任何 profile |

## 三 · 我建议的顺序

**先 C，后 A。** 理由：

1. **观感这一关你连否两版**（"非常不好看！推倒重来"）。让别人来测，第一轮该测的正是观感——这个用静态页就能拿到反馈，**不必先花掉"开一个对外实例"的授权**。
2. 真上课的验收需要"老师能回话"，而这一步目前**连你自己都没在真模型下验过**。让别人先撞上这个未验证的环节，反馈会全是"打不开／没反应"，测不出设计问题。
3. 顺序反过来（先 A）的代价：一旦实例开出去，任何一处崩（插件 render 抛错 → 槽永久崩、逃生门也跟着死）都得现场救，而你的人不在旁边。

**执行细节（等你说开始）**：
- C：我把夹具扩成 3 屏（阅读态／选项屏／板书屏）＋ 动效 demo，产出一个单文件 HTML；放哪由你定（本地文件 / 已有静态站 / 群文件）。
- A：先跑一次"在你桌面版人工验真模型回话"（1 分钟），过了再开实例——否则等于把没验过的东西直接给外人。
